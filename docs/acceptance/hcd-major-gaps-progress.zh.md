固定版式文字编辑回归另外发现自动聚焦竞态：刚打开 PPTX 文本框后立即全选替换，延迟 autofocus 可能重设选区，导致新文字与旧文字拼接。已将聚焦放到 EditorContent 挂载后的同步 layout effect，并加入连续 8 次进入、替换与取消的回归；PDF 和 PPTX 共用此编辑组件。

2026-11-15 增加 [Harness 多 Agent 与 PPT 整稿重建](hcd-agent-team-rebuild.zh.md)：人数可配置为 1–4，共享计划/发现、独占工作租约及释放、映射节点上层锁校验、PPTX 新页并行制作与原生导出预验收均有回归。真实模型三 Agent 已重做完整 3 页寿司介绍并保留售价 280；统一文字版式的生成仍不等于任意复杂演示稿设计。随后任务/锁已增加磁盘检查点和重启中断恢复，但运行仍限同一服务进程，没有分布式接管或自动续跑。
