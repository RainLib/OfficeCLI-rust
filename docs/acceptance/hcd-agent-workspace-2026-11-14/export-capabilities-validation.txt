Revision-aware export capabilities — 2026-11-14

GET /v1/documents/{id}/export-capabilities?revision=N returns source format, selected/head revisions, default format, and available output methods with disabled reasons and conversion/font warnings.

The editor uses this list, rechecks the saved revision, and does not silently change an explicitly selected method. Historical HCD packing, missing/mismatched originals and known source-rewrite restrictions are handled before download preparation.

POST /v1/documents/{id}/downloads/{format}?revision=N[&source=true] generates the file before issuing a ready link. Prepared files are immutable, expire after five minutes and are cached on disk with a 512 MiB aggregate limit. Conversion concurrency is bounded and CLI subprocesses have a timeout. Failed generation does not issue a ticket.
