# PPT/PDF 长文档的协作定位与按需加载（2026-10-25）

PPT/PDF 已有右侧在线协作、姓名标记、定位和跟随。本轮补齐：成员位于本机未加载页时仍可主动定位/跟随；跨页显示已保存操作对象的摘要；完整读取跨索引边界的页面续片，并修复进入/退出跟随引起的布局跳动。

## 交互与数据边界

- 定位或跟随先检查源文档的 chunk 范围和已保存版本，再按需补齐索引元数据，最后加载目标页面。页码仍按 canonical 前缀顺序计算，没有用未经验证的成员页码伪造稀疏页数。
- 本机操作、停止跟随、成员离开、连接/权限失效或版本更换会取消等待；迟到结果不能把页面再跳回成员位置。正在执行的共享索引请求可以完成并缓存，取消者不会继续请求后续索引或执行跳转。
- 索引请求共用进行中的 Promise，逐页获取；不因成员在第 130 页而把前 129 页的正文和图片都下载。元数据仍需读取到目标之前的前缀以计算页序，不宣称 O(1) 随机页码索引。
- 同一页面可能由多个 continuation chunk 组成。只有见到下一页的起点或 EOF，才将这组分片交给画布/缩略图加载器，避免在第 128 个索引条目处显示半页。
- 视图临时协议增加可选 revision，防止不同保存版本的位置误用于当前页面；旧客户端没有该字段时保留受限兼容。位置与操作摘要不写入正文、历史、导出或本机正文草稿。
- 跨页文字摘要通过鉴权后的 `/text/{nodeId}?revision=N` 读取已保存内容，重验 documentId、revision 和原生节点身份。固定布局里的未保存文字仍是本机草稿，不通过 Awareness 广播。图片缺少可读名称时显示对象类型。
- 摘要仅在协作面板打开时读取，两请求并发、最多 32 条缓存，每批最多 64 个不同文字对象；其他成员继续显示类型和位置。缓存按文档、接口和凭证隔离，迟到或取消结果不进入新会话。

跟随状态放进原有 35px 画布栏，显示/取消不会推动按钮或画布。缩略图保留固定比例的槽位，按页面实际比例居中缩放；加载完成不再改变行高，避免鼠标按下与抬起之间选到相邻页。原始页面和导出几何不变。

## 实现位置

- `fixedIndex.ts`：索引元数据、并发请求去重、续片完整性、取消和生命周期。
- `FixedViewer.tsx`：按需索引与现有本机草稿、SSE、画布的连接。
- `FixedLayoutEditor.tsx`：异步定位/跟随、稳定画布栏及缩略图。
- `fixedViewport.ts`：临时位置与保存版本绑定。
- `fixedActivity.ts` / `useFixedActivity.ts`：已保存对象的受限摘要。

原有文字、图片、几何的联合保存、冲突和自己的撤销仍走既有控制器；没有新增另一份协同正文或保存通道。

## 本地复现

```sh
npm --prefix examples/hdoc/editor test
npm --prefix examples/hdoc/editor run build
python3 scripts/hcd-fixed-lazy-preview.py --runtime-dir target/hcd-preview-runtime
```

样例分别有 130 页 PPTX/PDF，跨过每页 128 个 descriptor 的索引边界。终端输出 web 端口，使用 `.hcd-fixed-lazy-{pptx,pdf}-{writer,peer,reader}.html`。凭证仅写入该样例的权限 0600 私有配置；请求记录只含身份标签、方法、路径和时间，不含令牌。

先让 Bob 在缩略图区域进入第 130 页，再打开 Alice 的在线协作。Alice 仍只有首段 128 个页索引时，摘要应显示第 130 页的已保存文字；跟随无需预先手动翻完索引。样例对 Alice 的第二段索引人为延迟 4 秒，用于检查加载中手动离开与迟到结果。网络记录应仅有必要的索引、已显示缩略图、目标画布和对象查询。

## 本地验收

490 项前端测试及 TypeScript、独立版/嵌入版构建通过。新用例覆盖索引跨段、共享请求、取消、坏数据重试、关闭后迟到响应、续片完整性、视图版本、跨页摘要的鉴权/身份匹配和取消。

真实 CUA 两人长 PPT：Alice 仍只有 128 页索引时能看到 Bob 的第 130 页摘要；4 秒索引延迟中点击下一页，页面停在第 2 页，迟到响应未跳回；重新跟随到 130，再随 Bob 到 129。第 1 页本机草稿返回后完整保留，保存到 r1。缩略图加载后点击第 128 页仍准确落到第 128 页，跟随状态栏不再推动画布按钮。

长 PDF：Alice 从首段索引一次性定位第 130 页；只读 Reader 可主动跟随，文字仍只读且保存按钮禁用。200% 缩放时 Peer 的滚动 340/340、Reader 的 300/300 对齐，视口高度分别为 455/495。观察与跟随不推进 PDF 的 r0。

实际源文件导出：PPT r1 为 HIGH，130 页文字各出现一次、130 个图片对象保留，仅第一页 OOXML 修改；PDF r0 为 EXACT，130 页文字全部保留。两份文档都打包并解包验证原生 HCD。Alice 浏览期间 PPT 只请求 7 个不同正文分片，PDF 只请求 3 个（各共 130 个）；索引仅 0、1 两页，操作摘要另走单节点查询。该请求数量是命名样例的本地观察，不是所有浏览轨迹的固定上限。
