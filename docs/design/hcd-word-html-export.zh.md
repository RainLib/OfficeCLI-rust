# Word 区域模型的独立 HTML 导出（2026-10-27）

区域模型 2 现在可通过 CLI、鉴权 HTTP 和编辑器导出独立 HTML。导出读取指定的已保存版本，不修改正文、协作房间或原生历史。管理平台和提醒发送仍不实施，原七阶段目标保持未完成。

## 内容和纸张

- 文件保留完整 `hcd-flow-layout/2` 元数据、规范节点和引用载荷；按节使用源纸张尺寸、边距及默认/首页/偶数页 story 绑定。继承使用原生 `story_for_page`，缺少某个变体时不擅自借用默认页眉页脚。
- 首页优先级与逻辑页号的奇偶性分开；支持显式页号重启，没有重启值时继续计数。计算域保留保存的缓存文字，不重算 PAGE、目录或交叉引用。
- 正文节点只移动一次。反复展示的页眉页脚使用无编辑身份的视觉副本；规范 story 和载荷仍只保留一份，避免重复节点身份。
- 浏览器先等待字体和图片，再按块边界组装页面；测量时关闭 chunk 的惰性占位，组装完成后才对整页启用 `content-visibility`。原通用 DOCX 预览分页器在此路径关闭。
- 出错时恢复原始区域及子节点顺序，显示回退说明，不把半份文档当作完成结果。关闭 JavaScript 时原始区域仍存在；本次实际浏览器验收覆盖中途异常回退，没有单独验证禁用 JavaScript 的浏览器设置。

## 节点文件

节点声明的 HTML 静态快照优先用于展示；没有 HTML 编码器时保留可读 fallback、行内节点、富文本子块和惰性载荷。不把 DOCX 专用快照误认成 HTML 呈现。

所有节点资源均核对所选版本资产索引、声明长度、文件长度和实际内容哈希。已呈现图片使用 data URI；未在 HTML 快照中展示的文件放入可展开的“Attachments / 文档附件”，保留文件名和独立下载链接。资源元数据中的哈希和业务数据不被替换成 URI。文件名按 HTML 属性/文字转义，附件也受单资源和总输出预算约束。

## 入口与门禁

```bash
cargo build -p officecli
target/debug/officecli hdoc export example.hcd --revision 7 --to html \
  --output example-r7.html --fidelity-report fidelity.json --json
python3 scripts/hcd-word-html-export-verify.py --preview
python3 scripts/hcd-html-export-verify.py
```

HTTP 使用现有 `GET /v1/documents/:id/export/html?revision=7`，要求有效访问身份；CLI 与 HTTP 共用资源核验和呈现实现。CLI 原子发布，失败不覆盖已有输出。`export-options` 对区域模型 2 声明 `docx/html`；旧模型缺少规范区域身份时仍拒绝 HTML。前端仍先完成正常保存检查和兼容性复核，再导出指定版本，未接受 AI 建议不进入文件。

## 保留边界

这不是 Word 排版引擎。连续分节暂另起页，按整个段落/表格等块分页；单个超高块扩展显示而非切开，浏览器页数和 Word 可不同。负边距在浏览器展示中钳为零，原参数仍保存在元数据。未指定纸张尺寸时采用标记为默认的 A4。混合纸张的精确打印、逐行/表格拆页、计算域重算、HTML 再导入的分节往返尚未实现。

独立 HTML 是只读派生文件，不提供协作、提醒、AI 服务、原始 Office 关系或完整原生历史。完整离线归档仍使用 HCDZ。区域 PDF/Markdown 等格式、旧房间迁移、长文编辑虚拟化、跨设备恢复及原实施清单中的其他开放项继续推进。

## 区域 TXT 静态导出

区域模型 2 支持静态 TXT 导出：正文按节标记，独立页眉和页脚各列一次；图片只保留替代文字，布局、动态字段、资源和历史不在 TXT 中保留。界面需要服务端对应版本明确声明 TXT 能力，旧服务不启用该导出，并显示保真提示。原生多节文件测试、前端预检专项与隔离浏览器下载已验证，检查了正文、页眉页脚、图片替代文字、内部资源地址和版本不变；这不代表复杂文档的完整格式往返。模型 1、Markdown 和 PDF 仍不开放此路径。
