# Word 页面请求的设备持久化、旧标签页迁移与队列

2026-10-30。接续[正常页面设置](hcd-word-page-transactions.zh.md)和[正常链接入口](hcd-word-link-requests.zh.md)，将普通区域 Word `/2` 的页面请求从 sessionStorage 迁入 IndexedDB。现在正常页面、独立区域和链接三类原请求都能在关闭标签页后保留；停房草稿检查点编号、跨设备和完整目标仍须分别处理。

## 存储与迁移

- 页面请求使用专用设备库，按服务地址、文档、成员和协议隔离。当前 epoch 仍在每条完整原请求中严格核验；旧 epoch 或身份不匹配的证据不自动套用到新会话。
- 内部设备值是 `hcd-word-page-device/1` 队列，保留原 `hcd-word-page-request/1` 字符串；最多 16 条、总编码 8 MiB、每条 512 KiB。单条可下载完整原请求；队列不是正文或通用恢复包，不存会话 token、正文或附件。
- `prepare` 现在异步等待 IDB 事务提交，调用方必须 await 后才能发送。存储失败不能降级成未落盘提交；比较替换保护跨窗口创建、取消意图及清除。
- 旧标签页的原 key 保持可识别。迁移先将不同原字符串排队，完全相同的字符串去重；落盘成功且旧值仍相同时才清除 sessionStorage。迁移等待期间旧值变化则另行保留，不用新值覆盖前一请求。并发冲突有界重读，空间/容量/取消失败保留旧副本并阻止页面新操作。
- 不同旧标签页的请求不会互相覆盖。当前请求确认安装或取消后，用户明确结束才从队列移除；随后展示下一条。损坏或旧身份记录保留下载，不允许自动删除或发起新操作。
- 外部存储通知和焦点恢复会重新读取；回读代次保护阻止较早异步观察覆盖本窗口刚落盘的新请求。网络响应也必须匹配当前完整队列观察，队列中途变化时重新核对。

## 自动核对与取消

普通编辑器只对重开或从队列恢复的原请求在房间就绪后自动核对。用户刚确认并落盘的新请求由当前提交动作负责，不能被自动核对抢占。设备原请求和协作房间保持独立，房间替换不会清空原请求。

缓存不存在时继续使用原生不可变版本的签名回执核对，不重新提交或回退文档 head。取消意图先落盘；重开和服务重启后无论状态为 pending 或 recovery-required，都会继续核对同一次取消，不走 apply 或普通安装核对。服务端仍独立检查权限、所有权、确切请求与持久取消记录。

## 实际浏览器与文件验收

使用独立原生服务、真实侧车、三名普通嵌入页和仅回环的故障代理。UI 输入、确认、关闭、新标签页、下载均通过 CUA，没有通过脚本改写浏览器编辑模型。

1. Alice 正文保存 r2；Bob 的输入在页面确认前保存为 r3，旧确认因版本变化被拒绝，没有准备新事务。重新核对 r3 后，完整页面原请求在首次实际提交前由普通 UI 下载。
2. 页面事务将第一节 Letter 改为 A4 纵向，保存 r4。原三窗口 frame/loader 保持不变，正文完整、只读成员仍不可编辑。
3. 代理收到完整成功响应后丢弃，并阻止浏览器自动重复 POST 到达服务。只有一次实际页面提交。原窗口可通过原编号状态核对确认 r4，完整请求仍保留。
4. 关闭原标签页和其余测试成员、重启侧车后，在新标签页自动通过固定版本签名核对 r4；两次下载原请求逐字节相同。同账号另一普通窗口也能看到该请求；在那里明确完成后，原窗口同步移除面板。
5. 第二次页面请求想改回 Letter，代理在转发前阻止写操作。用户取消尚未准备的原请求，下载显示 operation=cancel。再次关闭标签页、重启侧车，在新标签页仍走相同取消；第二次下载取消请求逐字节相同。服务请求记录证明没有误转成安装检查或 apply。
6. 明确完成取消后，正常正文编辑保存 r5，纸张保持 A4。下载 `/6` 设备备份独立读取，包含双方正文及重开后输入、正确布局。
7. 受控旧标签页夹具通过可见按钮，将本批实际历史原请求写入旧 sessionStorage key 后导航到普通编辑器。两份不同原请求显示为 2 条；逐条核对原 r4 和取消状态，分别下载与原件逐字节相同；处理后仍是 r5，没有新文档修改。**这是受控旧存储输入的真实浏览器迁移验收，不是旧版生产编辑器运行或所有老版本兼容证明。**

实际 DOCX r4/r5 检查第一节纸张、双方文字、页眉页脚和原图片字节，r5 再导入校验。HCDZ 解包逐版本比对 r1–r5；规范文档与离线包均通过校验。取消请求的迟到提交返回拒绝，规范仍为 r5。详情见[浏览器范围](../assets/hcd-word-page-device-2026-10-30/browser.json)、[文件回读](../assets/hcd-word-page-device-2026-10-30/file-readback.json)和[实际请求](../assets/hcd-word-page-device-2026-10-30/requests.json)。

## 保持开放

本机 IDB 持久化仍受浏览器配额、清理和可用性限制；真实断电、存储被清空、跨物理设备、不同来源或旧 epoch 合并没有由本样本证明。受控旧标签页迁移不能保证未升级旧客户端同时写入的所有行为。旧身份或损坏队列不能自行丢弃，需匹配身份或另行恢复处理。

停房草稿检查点编号目前仍使用标签页存储；完整原请求下载不是可跨设备自动提交的恢复包。历史私有草稿比较/合并、页面/区域结构自身撤销、复杂区域复制、原稿混合导出、精确分页/连续排版、页码/自动目录和正文分段仍继续；PPT/PDF/Excel、字体/国际化、真实 AI、远端存储、多实例和生产验收仍保持完整范围。管理平台和提醒未做。

本批没有 Rust 修改或原生重建，使用有摘要的既有本机二进制；未重跑 Rust 全工作区或 Clippy，之前记录的 Clippy 失败仍开放。运行时凭证和签名私有日志不归档；本批窗口与进程结束后移除私有夹具根。
