# 包含行内容器的整块操作

本轮接通模型 3 内容参与整段和富文本块操作。原七阶段目标继续；管理平台暂缓，提醒只保留关联协议，不发送。

## 实现

块动作、块菜单、移动目的地和拖动目标使用当前编辑器的两类注册器。行内容器的保护插件现在同时提供实时 codec 解析和注册器 getter，不将可编辑权限写入共享文档或恢复文件。普通模型和没有显式安装行内策略的宿主继续保持原有保护。

- **复制**递归创建新的容器、普通业务节点、提及和正文来源身份；保留真实正文、数据、名称快照、格式及导出描述。复制后的附件继续引用同一已归档哈希，不创建虚假的上传任务，也不删除原件或历史文件。
- **移动**保留 occurrence、永久正文载体及正文项的身份；不先复制再删除。拖动和目的地列表都使用相同 codec 检查，不能跨越未知内容屏障。
- **段落样式转换**支持正文、标题、列表和引用，保留其中的行内容器和实际子树。代码块和破坏性分隔线转换仍不可用，实际事务也会拒绝，不仅依赖按钮状态。
- **删除和个人历史**继续使用现有结构删除与审阅链路。整个包含块删除后，同伴对隐藏正文的迟到输入仍保留；撤销能恢复这些内容，会重新隐藏同伴新输入的重做被拒绝。
- **暂存提交**再次检查当前文档、选区、存储格式和两类 codec；目标或经过的邻居注销后，暂存动作不得继续执行。缺少任何嵌套 codec 时，整个包含块保持保护。

本轮没有开放在行内正文中插入块结构；容器内部 `/` 的行内边界保持不变。自定义菜单仍通过统一命令执行这些动作，不另建一套无保护的操作入口。
