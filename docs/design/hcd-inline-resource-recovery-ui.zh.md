## 2026-10-28：导入任务的跨窗口可见性

恢复包中的文件任务经本机事务提交后，立即通过现有同源 BroadcastChannel 通知同一用户、文档和协作代次的其他窗口，再刷新当前窗口；当前窗口从导入开始即保持 pending，不能把导入途中当作没有待处理文件。多次异步刷新同时进行时，较早启动的刷新结果不能覆盖较新结果或错误状态。导入文件仍只是私有任务，关联和保存必须另行确认。

受控双客户端、共享 IndexedDB 测试验证事务提交后通知和另一个客户端读取，以及延迟旧刷新不会覆盖新任务；隔离浏览器中两个同用户标签页先均显示已保存，第一标签导入 r25 恢复包后，第二标签显示 `recovered-resource.txt`、待处理状态和禁用保存，见 `docs/assets/hcd-resource-window-notify-2026-10-28/second-window.png`。观察标签页可能触发已有焦点刷新，因此浏览器结果本身不能单独证明 BroadcastChannel 已送达。通知是异步的，后台冻结、消息丢失或跨设备不受保证；各窗口接到通知或重新聚焦后才刷新，不能声称已消除所有跨窗口保存竞争。

## 2026-10-28：普通语义保存的设备任务回读

普通语义编辑器在保存开始、向协作服务请求保存之前和返回保存成功之前，重新读取当前用户与文档的本机文件任务。即使另一窗口的通知未到，已提交的任务或本机存储读取失败也会阻止此窗口宣称保存完成；发现任务时刷新列表供用户处理。当前内容导出复用保存入口。若服务端已在最后一次检查前提交正文，检查失败仍保留该规范版本，但不把当前窗口当作可以安全关闭的完整保存。

共享 IndexedDB 的受控测试验证另一窗口写入但不发送通知时能够发现任务，以及设备读取失败时保护性阻断。该回读不能与另一窗口的写入、服务端提交或关闭动作形成原子锁：检查之后新任务仍可能产生；浏览器原生卸载、只读/历史导出、区域 Word 和跨设备不属于此验证。仍需统一跨窗口动作门禁与真实多窗口竞争验收。

## 2026-10-28：协作交接期间的设备任务检查

普通语义房间收到版本恢复的准备消息后，冻结当前窗口，并在等待保存、本机日志和协作同步的各个阶段回读设备文件任务；若发现任务或存储故障，不向服务端报告准备完成。冻结标志同步限制本窗口新建和关联节点附件，解除冻结后恢复原权限检查。冲突后“使用最新”也在备份、切换协作代次前后检查设备任务；即便服务端已切换，仍发现任务时保留窗口并要求处理，而不声称切换完成。

共享 IndexedDB 的受控两客户端测试在日志排空或协作同步期间让另一窗口写入附件任务，交接均拒绝 ready；既有恢复客户端测试仍通过。检查仍非跨窗口原子锁，通知或最后一次检查之后可能出现新任务；实际浏览器跨窗口精确时序、异常断线和区域 Word 仍待验收。已经提交的服务端操作不会因本地后续检查自动回滚。

## 2026-10-28：恢复完成后的本机保全检查

普通语义恢复完成后，发起方回执、协作通知和已准备窗口的 HTTP 代次发现统一进入同一后续检查：先写完本机正文副本，再核对仍在途的图片及设备节点文件，只有窗口仍有效且没有待处理任务时才切换到新代次。发现文件或图片、或本机刷新失败时，旧窗口保持冻结并打开冲突/草稿恢复入口；已在服务端完成的恢复不会回滚，用户可先下载本机草稿（包含待处理节点文件）或明确处理任务。重复通知期间只执行一次检查。

共享 IndexedDB 的受控双客户端测试覆盖“已报告 ready 后、跟随新代次之前，另一窗口写入文件”：切换被阻止、任务可见，明确取消任务后可以继续。当前没有做真实浏览器多窗口的该精确竞争及服务端恢复已提交后的故障注入；最后一次本机检查与代次切换仍非跨窗口原子操作。

## 2026-10-28：旧协作代次的本机文件选择

普通语义编辑器的恢复面板可列出本机同一服务、文档、用户和编辑模型下较早协作代次的未完成节点文件。用户明确选择后，先重新读取旧任务、检查其状态及文件 SHA-256，再核验当前会话的写权限，复制为本机当前代次的待处理任务；原任务不会自动删除，文件不会自动上传或关联。复制使用稳定的新任务 ID，同一次选择重复导入不会重复创建，也不会复活当前代次已终止的任务。当前节点不存在时，定位操作明确提示文件保留在本机，关联按钮保持禁用。

隔离样例使用测试页向本机 IndexedDB 写入合成的旧代次任务：浏览器列出并明确复制，缺失目标时显示提示；另一份同机旧任务定位到现有行内容器，确认关联后保存 r28。独立读取规范资源核对文件字节，并将 HCDZ 解包、校验及比较 r28 投影；证据在 `docs/assets/hcd-older-node-files-2026-10-28/`。36 项相关专项、完整前端 1161 项及 TypeScript/应用与嵌入构建通过。

该入口不自动恢复旧正文或跨设备文件，也不将旧任务变成新代次的协作授权；复制和旧代次中另一窗口取消之间没有跨数据库原子锁。不同用户、不同文档、服务或模型的文件不列出。浏览器缺少数据库枚举能力或本机存储不可用时显示错误；旧会话目标被删除后需保留备份或取消任务，不能任意关联到其他节点。截图与文件证据均为合成样例，不代表物理多设备或生产验收。

## 2026-10-28：直接下载待处理原文件

普通语义恢复的旧会话文件列表，以及普通语义/区域 Word 已显示的待处理文件面板，提供“下载原文件”。下载前从本机任务记录读取并校验 SHA-256；当前任务会再次读取以确认仍存在且内容一致。下载不上传、不关联节点、不清除任务，也不依赖写权限；文件损坏或任务已结束时提示读取失败。原节点缺失时提示可下载原文件或取消选择。

隔离浏览器使用同机合成的旧会话文件，分别从旧会话列表和当前待处理面板实际下载，独立读取两份文件字节均与样例一致；任务仍保留、文档仍为 r27。截图及摘要见 `docs/assets/hcd-node-file-download-2026-10-28/`。相关组件测试覆盖损坏、取消与无额外上传；本次没有验证不同物理设备、区域 Word 恢复启动页或系统文件权限异常。下载是本地文件副本，不自动迁移任务、正文或附件引用。

## 2026-10-28：区域 Word 的文件操作边界

区域 Word 的保存、当前内容导出和关闭现在主动读取共享设备日志中的节点附件及图片上传选择，不再只依赖窗口通知和内存状态。保存完成后再次检查；如果这期间出现任务，不把结果用于导出或关闭。图片上传的服务端任务列表未知或设备读取失败时也保持保护状态；新发现的设备图片选择显示在图片上传任务中，仍需用户处理。任务查询不会自动上传、关联或删除文件。

共享 IndexedDB 的受控双客户端测试覆盖另一窗口写入但未发送通知、存储读取失败、未知上传任务列表和读取期间产生新任务；这些是组件级证据，尚未完成真实浏览器中的精确跨窗口竞争。设备检查与其他窗口写入之间没有跨窗口原子锁；服务端已经提交的保存不会因后续发现本机任务而回滚，浏览器原生卸载也无法等待异步设备检查。跨设备和恢复启动页仍不在本次覆盖范围。

### 区域 Word 漏通知的浏览器验证

使用隔离区域 Word 样例和同源测试页，在编辑器显示已保存 r1 后，测试页延迟向同一成员的设备日志写入合成节点文件且不发送通知。编辑器依然显示已保存；点击保存后发现该任务，阻止保存并展示任务。取消测试任务后，保存重新可用并仍为 r1。再次写入任务后直接点击 DOCX 导出，也在保存前发现任务并阻止导出；[截图](../assets/hcd-regional-file-boundary-2026-10-28/export-blocked.png)显示保护提示与文件任务，规范 manifest 的 revision 仍为 1。

测试页调用正式设备日志 API 创建合成记录，未使用实际文件选择器，也未测试上传中的准确时序、区域图片选择、关闭按钮或跨物理设备。首次浏览器验证发现命令错误处理覆盖了中文提示，已修复并在重载后的同一测试中确认。该浏览器验证不改变上述非原子边界。

## 2026-10-28：附件重试的服务端重新固定

同一个设备附件在上传成功后重新关联时，原先会再次发送完整文件。现在首次选择仍直接上传；对已经归档的任务及恢复包中的待暂存资源，默认传输先提交哈希、类型和长度，请服务端从当前文档已有规范资源或暂存资源重新固定。服务端在文档写锁内检查来源、字节长度、SHA-256 和图片格式，再写入新的暂存记录，避免与垃圾回收竞争。不存在时或旧服务不支持该接口时才上传原文件；权限、网络、类型和完整性错误不会降级为上传。固定只准备资源，仍需原有的明确关联、文档保存和回执流程。

测试覆盖已暂存与规范资源、错误类型、损坏、无权限及资源缺失；组件测试覆盖选择后再次关联只发送一次文件正文。隔离原生 HTTP 测试调用实际前端传输两次：首次上传一次，第二次仅发送固定请求，暂存资源回读与原字节一致，文档版本仍为 r0，见 [HTTP 摘要](../assets/hcd-node-resource-repin-2026-10-28/http.json) 和 `scripts/hcd-node-resource-repin.mts`。此优化不证明节点定位慢已解决，也未覆盖真实多窗口竞争、远端多实例暂存或附件删除后跨设备恢复。

恢复包中的规范资源随后也改用重新固定：仅 GET 当前资源无法防止协作者在恢复比较之后、最终保存之前移除该引用。新的路径在合并前建立暂存保护；旧服务或资源缺失时回退上传，其他错误保持失败并保留恢复内容。历史记录中的“零 POST”是当时的 GET 验证，不描述当前的固定请求。

原生服务测试进一步构造 r1 资源仅存在于当前规范索引的情况，重新固定后将文档恢复到不包含该资源的 r0，再用保留的暂存记录在 r3 重新关联，资源哈希保持一致。隔离 HTTP 测试确认规范资源重复恢复不上传文件正文，新资源首次上传一次、第二次重新固定；规范 root 和版本未改变，见[请求与摘要](../assets/hcd-recovery-resource-repin-2026-10-28/http.json)。该验证使用受控的版本恢复和图片资源，不等同于真实协作者同时删除业务节点的浏览器验收。

## 2026-10-28：区域 Word 同设备文件动作协调

支持 Web Locks 的同源浏览器中，区域 Word 使用该成员、文档和协作代次的设备日志名称作为锁范围：新增节点文件任务或图片选择写入设备日志时，与保存、当前内容导出和关闭串行。动作持锁期间仍读取设备日志并核验上传状态；已存在的任务会阻止动作，晚于动作取得锁的选择在动作结束后才写入。导出持锁覆盖保存和下载，关闭内部保存复用已取得的锁，避免嵌套锁。

共享 IndexedDB 与模拟锁的双客户端测试覆盖两个窗口的节点文件和图片选择等待、动作结束后任务可见，以及任务先存在时阻止后续动作。该保护不覆盖尚在计算哈希、尚未请求写入的选择，不同浏览器来源、物理设备和旧客户端也不共享锁；浏览器不支持 Web Locks 时沿用原有动作前后回读，不能视为原子保证。当前没有真实浏览器精确竞争或原生卸载验收，普通语义模式仍需单独协调。

## 2026-10-28：普通语义编辑器同设备节点文件协调

普通语义编辑器的节点文件选择和恢复导入写入，与保存、当前版本导出、关闭及切换窗口化视图使用同一设备日志的 Web Lock 排序。动作持锁时仍重新读取待处理任务；导出覆盖保存与下载，关闭和切换复用锁内保存。已接收但等待锁的设备写入在日志关闭前完成。

共享 IndexedDB 和模拟 Web Locks 的测试覆盖另一窗口选择与导入等待、操作结束后任务可见，以及等待写入期间关闭日志。该证据为组件级模拟，不代表真实浏览器精确竞争验收。此锁只覆盖节点文件任务，不覆盖普通语义图片选择、文件哈希计算完成前的窗口、历史恢复及跟随恢复的完整切换、原生卸载、旧客户端、跨来源或跨物理设备；无 Web Locks 时仍只有原有回读检查。

区域 Word 设备日志的关闭流程进一步覆盖锁排队：已经接受、正在等待文件动作锁的图片选择和节点文件写入，会在数据库连接关闭前完成；关闭开始后不再接受新的文件选择。多次关闭等待同一个关闭结果。普通语义节点日志也统一了重复关闭时的等待语义。共享 IndexedDB、模拟 Web Locks 的测试分别覆盖两种区域文件及语义文件；这仍不是浏览器原生卸载或真实跨窗口文件选择验收。

## 普通语义图片任务：设备日志准备

新增独立的语义图片选择日志，按成员、文档、协作协议和 epoch 隔离，保存原始图片字节、哈希、图片基线以及选择时已经看到的协作意图；写入与同范围节点文件动作使用同一设备锁。日志有数量和容量上限、哈希与快照校验、终态防复活以及关闭时等待已接受的操作。测试覆盖重开、字节损坏、取消、并发协作者的未见替换、锁排序和输入对象修改。

**尚未接入编辑器图片选择、任务面板、恢复、保存/导出门禁或恢复包。** 因此普通语义图片替换目前仍使用原有上传流程，不能声称图片选择已获得设备恢复保护；还需实现明确重试与取消、幂等关联和协作同步/持久化回执后再清理字节，并完成浏览器验收。

设备日志现增加明确的 `applying` 阶段和图片文件客户端：应用协作意图之前持久记录该阶段，失败保留原字节；重试只认同 ID 的精确意图，如果该意图已被保存回执清除或无法确认，则保留任务并停止自动重放。测试覆盖离线上传失败、同步未确认后的重试，以及意图被消费后的不确定状态。协作图片草稿提供选择时快照方法，复用原有冲突规则。

这些仍是底层组件，**尚未接入普通语义编辑器的图片选择或用户任务面板**；不确定状态的可理解提示、人工处理、设备日志发现及门禁仍需实现和验收。当前测试的同步和暂存为注入模拟，不代表真实协同服务已验证。

## 普通语义图片任务接入

普通语义编辑器的图片侧栏已使用设备任务：选图先记录字节和协作快照，再显式暂存与关联；侧栏提供状态、重试、下载原文件和取消。结果不明时，用户可先检查文档、下载文件，再经确认放弃本机重试记录；该操作不撤销共享内容。同源同成员同文档同 epoch 的节点文件锁也用于图片操作，保存、当前内容导出、关闭、窗口切换和恢复交接会检查图片设备任务。无法使用设备存储或锁时保留保护，不自动重放。

测试覆盖文件失败、协作同步期间本地尚有待发更新、重复重试、结果不明与人工放弃；使用的是组件级模拟。还未完成真实浏览器多窗口、进程崩溃、真实协作服务及跨设备验收；协作者所在其他设备及旧客户端不会看到这台设备上的私有任务。语义恢复包尚不携带图片任务字节，存在待处理任务时不能把它描述为完整图片恢复包；区域 Word 等其他模式各有自己的边界。当前复用选择时的客户端身份，跨窗口恢复的个人撤销还需验证。

隔离本地浏览器验证：测试页按实际设备日志 API 写入合成图片任务后，已打开的普通 Word 编辑器主动核对发现任务；再打开同一成员、文档和来源的第二窗口，自动显示待处理状态并禁用保存。该窗口的关闭被阻止并提示处理图片任务，当前内容导出也未执行；服务端文档仍为 r1。测试不涉及真实文件选择、上传、重试、实际进程终止或跨设备。

补充修正动作边界读竞争：如果旧的空读取返回前，新读取已发现任务，或读取期间编辑器运行时已经切换，不能放行操作；组件测试覆盖交错读取和存储失败。页面卸载后旧任务也不再向已关闭的通知通道发送消息。

隔离原生服务与真实协同 WebSocket 补充验证：注入暂存前的网络失败后，保留选图字节，关闭并重开设备日志，再明确重试；两名协作者的客户端收到同一图片意图，暂存请求一次，联合保存由 r1 产生 r2。r2 的图片资源读取及语义重建 DOCX 内的图片均与选择文件逐字节一致，测试摘要见 [evidence.json](../assets/hcd-semantic-image-service-2026-10-28/evidence.json)，执行脚本为 `scripts/hcd-semantic-image-service.mts`。设备 IndexedDB 和 Web Locks 使用模拟实现，故这不是浏览器真实选图、崩溃或线上服务验收；注入失败发生在上传前，并非提交后响应丢失。

### 图片恢复包格式准备

语义恢复包底层增加 `/2` 格式：有待处理图片时可在隔离候选中携带图片任务的原始字节、身份、选择时快照及 `chosen`/`staged`/`applying` 阶段；按资源哈希去重、校验字节和限制总大小，不接受额外字段、重复任务或终态任务。没有图片任务的包仍写 `/1`。测试覆盖 `/1` 兼容、`/2` 往返、损坏及不确定状态的保留。

**该格式尚未接入用户界面的导出或设备任务导入。** 当前恢复比较明确拒绝含待处理图片的 `/2` 包，避免在缺少确认、去重和门禁协调时自动重放；已有共享图片草稿也仍会被明确拒绝。跨设备恢复、浏览器文件往返以及实际协作验收均未完成。

### 图片任务恢复包导出接入

普通语义编辑器现可在支持 Web Locks 的同源窗口中，在共同设备锁内捕获正文、节点文件及待处理图片任务，再生成恢复包。捕获期间检测到文件准备或读取失败时不导出；文档继续编辑不改变已捕获的副本。含图片任务的下载会明确提示目前不能从编辑器导入，要求保留恢复包和原图；没有图片任务时沿用 `/1` 格式。共享协作图片草稿仍不支持打包，继续拒绝，避免生成不完整副本；无 Web Locks 的浏览器当前不能使用此恢复包导出入口。

隔离浏览器通过正式设备日志 API 写入一个合成任务后，实际点击“导出恢复包”并下载；独立解析下载文件确认 `/2`、`chosen` 和原始测试字节完全一致，界面显示导入未支持提示，服务端仍为 r1。该验证未进行实际文件选择、图片上传、导入、跨设备或进程崩溃。组件测试覆盖锁内采集、文件准备中断以及格式和校验；图片任务导入仍是后续工作。

### 图片任务设备导入准备

设备日志已支持按同一范围锁原子导入图片任务批次，核验字节哈希、任务身份和容量；重复导入不创建副本，本机仍保存的完成或取消记录不被复活。已有任务不会从 `applying` 降级回可重放状态。对于本机没有记录的恢复包任务，统一标为 `applying` 待核对：导出恢复包之后，原设备可能已经完成或取消该替换，单凭旧包不能证明可以重新应用。测试确认此类任务不会自动上传或重放。终态记录有数量上限，旧终态清理后再次导入仍进入待核对状态。

此步骤只完成设备日志能力，**恢复包比较和确认界面尚未调用该导入方法**；目前仍不能从编辑器导入带图片任务的恢复包。后续需要在恢复比较、权限检查、正文合并和设备任务之间协调失败与并发，并提供清晰的人工核对流程。

### 图片任务恢复包导入接入

普通语义编辑器现允许比较包含设备图片任务的 `/2` 恢复包，展示任务数量和名称；明确确认后先写入本机图片任务，再在共同设备锁内复核权限、文档和其他图片任务，最后合并已比较的正文。新设备上的任务保留为待核对，不自动上传或应用；侧栏说明先下载原图、检查文档，再决定是否重新替换。重复导入不会恢复仍有终态记录的任务。

若导入图片后权限、文档或其他设备任务发生变化，正文合并停止，已写入的图片任务保留；界面提示合并结果需核对。组件测试覆盖正常导入、协作者修改、其他窗口任务竞争、重复和容量限制。当前没有真实浏览器选择恢复包及跨设备验收；共享图片协作草稿仍明确拒绝打包，恢复包只在相同文档、协议与协作代次下接受比较。原设备操作、旧客户端和跨设备之间不共享本机锁。

隔离本地服务补充验收：使用前述浏览器实际下载的合成 `/2` 恢复包，在包的隔离候选中增加测试正文后执行比较与确认；原生 HTTP 校验和两个真实 WebSocket 客户端参与。另一协作者原有文字保留，恢复正文同步到另一客户端；图片字节原样保存为待核对任务，尝试继续时未产生自动暂存或重放。此时服务端版本仍为 r1，未验证后续保存。测试使用模拟 IndexedDB 与锁，不等同于真实浏览器文件选择、设备崩溃或跨设备验收。详见[结果](../assets/hcd-semantic-image-recovery-import-2026-10-28/service-evidence.json)、[合成源包](../assets/hcd-semantic-image-recovery-import-2026-10-28/source-synthetic.hcd-recovery)与 `scripts/hcd-semantic-image-recovery-service.mts`。

### 协作图片草稿的原始文件保全

在图片属性中的未保存图片列表，以及冲突候选项中，可单独下载草稿的图片资源。读取时先尝试当前规范资源，资源不存在才读取暂存资源；其他权限和网络错误不降级。下载前限制大小并校验 SHA-256，从文件签名识别扩展名；失败不会改变草稿或文档。测试覆盖暂存回退、权限失败、字节损坏和响应大小限制。隔离原生服务验证规范资源与暂存资源都能回读精确字节，版本不变，见[结果](../assets/hcd-image-asset-backup-2026-10-28/evidence.json)。

这只是原图保全，不包括图片位置、冲突选择或协作意图，也不替代支持图片草稿的完整恢复包；真实浏览器点击下载与资源过期场景仍未验收。

### 协作图片草稿备份

普通语义恢复包新增 `/3`：当协作状态中含图片草稿时，保留完整草稿状态，并按哈希读取所需原始和替换图片资源，验证字节后归档；重复资源只存一份，受文件与资源总量限制。资源不可获取、字节损坏或超限时不生成包。只有设备图片任务、没有协作图片草稿的包仍为 `/2`，原有无图片任务包仍为 `/1`。
