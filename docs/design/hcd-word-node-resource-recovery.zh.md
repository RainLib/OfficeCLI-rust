# Word 区域节点文件的中断恢复

2026-10-27。承接[区域节点 SDK](hcd-word-nodes-regional.zh.md)，补齐显式 `hcd-word-regions/1` 编辑器的未完成节点文件选择。管理平台暂不做，提醒协议不发送。

## 实际行为

选择文件后，先计算摘要，将原文件字节、名称、媒体类型、资源键、原目标节点载荷和所在区域写入当前成员的本机日志。事务成功后才请求原生资源归档。每个文件最多 8 MiB，最多 16 个待处理文件，总字节最多 64 MiB。没有 token、临时 URL 或可执行脚本进入记录。

首次选择仍可直接关联：资源归档完成后，通过现有 `node.resources` 命令核对原节点、选区、权限与扩展定义；选区或节点在等待期间变化就不自动关联。日志仅记录选择，不能作为协同或作者身份的授权。

重开后，底部“待处理节点文件”打开右侧属性区域。显示原目标和当前选中的目标，支持定位、继续上传、确认关联和取消。重开本身不上传、不修改正文、不自动套用旧节点属性；确认关联使用点击时看到的当前节点载荷，等待期间的新修改仍会使命令拒绝旧载荷。缺少扩展、目标已删除、区域变动或权限不足时保留文件，不能绑定到其他节点。

上传失败或连接释放保留文件字节，再次上传不需要重新选择文件。只有正常编辑命令完成、资源在结果节点中可见，且本机文档更新已写入日志后，选择才标为已关联。上传成功不等于文档已保存；实际保存、导出与关闭仍等当前文档回执。

取消会中止进行中的请求并保留不含文件字节的终态标记。另一个窗口或迟到响应不能将它重新变为待关联记录。已经进入正常编辑命令提交的短暂阶段不再显示可取消，避免界面一边说取消成功、一边提交节点。已到服务端的不可变资源不会因为取消被删除，也不会自动绑定。

## 保存、本机数据与兼容

- 初始化日志、准备文件、上传、待确认关联与日志读取失败都计入资源未完成状态，不能误显示“已保存”或通过旧回执关闭。
- 本机日志按 API/协同端点、文档、成员和 epoch 隔离；同作用域窗口通过广播和重新获得焦点核对状态。其他成员可以保存自己的已同步修改。
- 记录沿用现有设备库的独立元数据键，不混入 Yjs 文档，也不将缓存重放为共享权威。文档 wire、签名请求和原生资源 API 均未改变。
- 文件选择写入被拒绝时不发上传请求，也不使正常正文更新日志永久失败。记录读取或文件字节完整性检查失败时保留阻断状态。
- 下载设备草稿包含待处理节点文件及其字节。DOCX/HCDZ 正式导出仍要求先完成或取消文件选择；已经关联的资源进入对应文档版本和离线历史。
- 节点资源沿用既有编码器、导出适配和稳定实例 ID；关联操作沿用字段意图、个人撤销和重做，不覆盖同伴的新属性。

## 已核对的证据

合成 fixture 为 `target/hcd-preview-runtime/word-room-8rc2yi8n`，预览为 `http://127.0.0.1:63170/node-resource-alice.html`。使用真实嵌入组件、两个已鉴权浏览器成员、生产 sidecar、原生服务及实际文件。

| 步骤 | 实际结果 |
|---|---|
| r2 | 浏览器插入资料卡片并保存 |
| r3 | 第一份 PNG 正常归档、关联并保存 |
| r3 后 | 第二份文件写入本机日志，代理返回 503；新窗口仍显示待处理、禁止保存，上传计数未因重开增加 |
| r4 | Bob 修改名称为“协同后资料”并保存，Alice 的本机文件仍待确认 |
| r5 | Alice 定位节点，看到原名称和当前名称，确认恢复关联；不重新选文件，保留 Bob 的名称和原资源 |
| r6 | Alice 个人撤销只移除第二份资源，Bob 名称与原资源不变 |
| r7 | 重做恢复第二份资源 |
| r7 后 | 两次慢请求期间取消，再释放迟到请求；文件未绑定、没有新版本，界面仍为已保存 r7 |

首次使用直接断开连接时，浏览器自动重试并成功归档了第一份文件，因此不将那次观察作为“失败保留”的证据。失败恢复使用之后明确返回 503 的第二份文件。代理仅存在于合成 fixture，没有加入产品测试开关。

完整 914 项前端测试通过；其中 9 项新增覆盖持久后才上传、关闭/重开不自动修改、取消胜过慢响应、不同窗口取消防复活、失效权限/过期选区、字节损坏、磁盘写入失败、准备阶段取消及提交阶段取消门禁。最终界面调整后，15 项设备/资源专项再次通过；TypeScript 与独立页、嵌入构建通过。

浏览器下载的 r7 DOCX 与原生导出逐部件一致，仅排除新生成 `w:paraId`。图片绘制关系实际引用两份归档 PNG 的字节。HCDZ 解包后 r0–r7 状态逐版相等，资源摘要一致，原生和离线校验通过。证据、日志、源文件摘要与 DOCX/HCDZ 位于 `docs/assets/hcd-word-node-resource-recovery-2026-10-27/`。
