# 区域 Word 标题大纲与长文保存回执

2026-10-27。承接[区域 Word 浏览器](hcd-word-browser-regional.zh.md)与[纸张工作区调整](hcd-word-paper-ui.zh.md)。管理平台、实际提醒发送继续暂缓，原七阶段仍有开放项。

## 大纲行为

- 左侧导航继续默认收起，通过视图命令或底部入口开启，面板可独立关闭。节导航与标题大纲在同一按需面板中。
- 收集所有正文分节中的标题，包括引用等富文本块中的标题；不把页眉、页脚、未绑定 story 当作正文目录。
- 条目保留标题级别、所属节与永久结构 key。同名标题不混淆；协作者改名、前面插入段落以及规范保存替换来源 ID 后仍指向原标题。
- 点击跨节条目先返回正文模式，再选择当前标题位置并仅滚动文档容器；选择事务不写文档、不触发保存、不进入个人撤销。已删除或转换的目标显示独立状态说明，不误报为保存失败。
- 支持搜索；列表初始渲染 80 个标题，接近底部或点击继续加载后增加下一批，保留键盘按钮回退。使用一帧合并文档更新，卸载清理监听、动画帧和观察器。新增文案覆盖现有五个语言入口。

这是导航大纲，不是插入到 DOCX 中的自动目录，也不是 Word 精确分页。按批次显示仅覆盖大纲列表，正文长文虚拟化尚未完成。

## 保存问题与修复

真实 183 标题、两节文档暴露了“原生提交 r2，但客户端等待回执时断连”的问题。初次运行还出现所有权失效；独立运行仍断连，因此不能归因为并发检查占用机器。

来源回执原来在区域模型外层写事务内执行所有来源规划。结构投影缓存有意禁止在写事务内复用，逐个叶节点读取因此反复重建整篇文档，阻塞侧车消息处理。现在先在事务外准备并验证全部来源动作，随后同步进入一个事务提交来源与布局；中间没有异步间隔。无效末尾来源仍拒绝整个操作，不留下前面区域的部分重绑。

协调器另外在初始化与保存的模型阶段之间主动维护已有所有权；原生 15 秒期限、本地提前到期、签名、CAS 与未知结果保留规则没有放宽。维护失败后仍拒绝继续写入，原生提交后的维护失败保留精确准备请求，不能把规范版本已增加等同于客户端保存成功。

## 可复现证据

```sh
cd examples/hdoc/editor
npm test
npm run build
cd ../../..
python3 scripts/hcd-word-outline.py
```

运行脚本只创建 `target/hcd-preview-runtime/word-outline-*` 隔离文档，使用生产侧车及真实原生接口，不修改用户文档。验证 183 个正文标题、两个同名标题的不同身份、页眉标题排除、两人分节输入、保存回执、重连、大纲身份不变、DOCX 正文/story 位置和 HCDZ r1/r2 精确回读。成功记录在 [原生与文件结果](../assets/hcd-word-outline-2026-10-27/native-and-files.json)及[Socket 日志](../assets/hcd-word-outline-2026-10-27/socket-test.log)。该次请求到成功回执约 2 秒，属于本机合成样本数据，不是性能上限承诺。

前四次失败运行保留在隔离目录；其中前两次另有资产日志。成功用例没有减少标题数或放宽所有权期限。新增测试覆盖来源规划不在写事务内逐条重建，以及错误末尾来源不会发布部分 ID/布局。

最终前端全量 **1100 项通过**，包含 8 项大纲测试、3 项所有权维护测试和 2 项区域来源回执回归。最初 TypeScript 检查暴露测试夹具的 `kind` 字面量推断错误，已修正；新增回归第一次还使用了错误的平铺顺序/错误文本预期，修正后纳入全量通过记录，失败日志另存 `region-receipt-first-attempt.log`。没有修改 Rust 源码，本轮未另跑 Rust 全量测试。

最终 `npm run build` 退出码 0：TypeScript、应用构建、嵌入构建均通过，[构建日志](../assets/hcd-word-outline-2026-10-27/frontend-build.log)保留现有依赖的 `use client` 指令及 chunk 大小提示。它们没有作为构建失败隐藏，也没有在此增量扩大为独立打包改造。

按 React 检查表复核了稳定 attach 回调、编辑器挂载后定位、共享文档监听清理、RAF 合并、筛选 memo、IntersectionObserver 释放和键盘加载入口；未引入新的 UI 依赖。尚未通过浏览器检查的交互见下文。

## 浏览器与剩余边界

本轮浏览器先失去连接，短暂能重新列出内置标签页，但读取已有页与新建页再次超时/报告不可用。因此本轮没有大纲组件的实际点击、搜索、批次滚动、缩放几何或截图证据；不能把模型/Socket 检查当作视觉验收。隔离预览可用 `python3 scripts/hcd-word-outline-preview.py <成功隔离目录>` 重开，保留原签名日志和版本，不重置房间。

后续还需完成浏览器大纲交互、标题被协作者删除时的定位反馈、完整可访问性、正文自动目录/页码重算、精确分页、跨节连续排版和正文虚拟化。行内容器附件恢复的明确关联/复存及浏览器撤销/重复导入仍是独立待验收项。区域入口仍受 `HCD_WORD_ROOMS` 开关控制，旧文档没有被此改动自动迁移。

### 浏览器补验

同日后续连接短暂恢复，在成功隔离目录的实际区域编辑页补验：初始导航收起，点击“节导航”后显示首批 80/183 条；搜索 `Long outline 180` 后点击条目，切换到第 2 节，真实选区落在该标题，标题出现在文档可见区域。继续滚动大纲后实际条目数按 160、183 增加，末尾为 `Long outline 180`，加载入口最终消失；独立关闭后导航 DOM 已移除。全过程界面保持“已保存 · r2”，没有输入或保存内容。

见[搜索与跨节定位截图](../assets/hcd-word-outline-2026-10-27/browser-outline-locate.png)。先前“尚无浏览器证据”是上一轮的历史状态，上述基础操作现已有证据。精确批次按钮点击未验收：自动滚动触发观察器后按钮标签/存在状态已变化，两次按旧状态定位按钮失败；不能把自动加载结果写成键盘加载按钮通过。IME、协作者删除目标的实时反馈、键盘可访问性、响应式几何以及正文虚拟化等边界仍保留。后续附件页的定位步骤再次阻塞，浏览器整体连接随后不可用，不影响已取得的大纲证据。
# 2026-10-28：正文大纲快照

区域 Word 的大纲导航新增“插入大纲快照”：将各节正文的完整标题按顺序插入当前正文块之后，保留标题层级的文字标记，不覆盖选区。它是可编辑的普通正文，复用现有协同、个人撤销与保存机制；不包含页码、可点击目标或自动更新。页眉页脚的标题不参与生成。超过 4000 个标题或总文字超过 100 万个 UTF-16 代码单元时拒绝生成，不截断写入。用户需在可编辑正文放置光标，工具提示明确展示这些边界。

本机两个浏览器成员的隔离测试验证插入、协作可见、保存 r2、保存后撤销与重做，以及同伴继续输入；当同伴修改被撤销影响的内容时，系统保留其内容并显示删除冲突。过程中修复区域房间对保存后重做的来源误拒绝：仅允许同一隐藏载体中、经过规范基线确认的同一区域来源恢复；不完整的历史载体不提供来源授权。实际语义 DOCX 回读包含大纲文字，HCDZ 解包及校验通过。截图与文件位于 `docs/assets/hcd-word-outline-snapshot-2026-10-28/`，它们来自本机合成样例，不代表完整自动目录、精确分页或跨主机验收。

### 协作冲突处理补充

区域编辑器遇到同伴修改阻止个人撤销时，显示可取消或保留当前内容并跳过该条记录的提示；跳过前重新核对历史状态。本机双成员浏览器验证了提示、取消与跳过，见[提示截图](../assets/hcd-word-region-conflict-2026-10-28/history-review.png)。删除草稿冲突接入右侧审核面板：恢复或确认删除前，先在隔离副本上检查区域结构和房间守卫，再核对最新冲突状态；无法安全定位的跨区域恢复保持禁用。模型测试覆盖恢复同伴文字、确认删除和过期选择拒绝。

随后在隔离预览中使用两个真实协作连接并发删除与修改同一正文块，并在浏览器补验审阅面板：显示删除时内容和同伴最新内容，恢复后保存为 r7；再次构造冲突，选择继续删除并二次确认后保存为 r8。对应的语义 DOCX 文件正文回读表明 r7 包含同伴修改、r8 不含该块，其他正文保留。见[审阅面板](../assets/hcd-word-region-conflict-2026-10-28/deletion-review.png)及[删除确认](../assets/hcd-word-region-conflict-2026-10-28/deletion-confirm.png)。并发由本机两个 WebSocket 测试客户端构造，选择和保存由浏览器完成；尚未验证两名真人同时操作、实际 Word 打开效果或生产部署。语义导出的分页、域和部分版式仍有既有降级。

### 长标题搜索

区域大纲原来先把标题缩短到 256 个字符再搜索，标题后半部分无法匹配。现在按完整标题搜索，结果仍限制显示长度，并在匹配位于后部时展示附近的片段；空标题使用当前语言的名称搜索。生成静态大纲仍使用完整标题及原有数量和长度上限。15 项大纲和区域布局专项通过，包含长标题、表情和空标题；本次没有新增浏览器搜索验收，也没有实现正文分段加载或自动更新的 Word 目录。

后续在全新隔离区域 Word 房间补验：浏览器创建超过 256 字符的标题，搜索尾部关键词可找到带匹配片段的条目并定位到标题；搜索无结果时仍可插入全部标题的静态大纲快照，保存为 r4。语义 DOCX 回读确认长标题和末尾另一节标题各在正文与快照出现一次，其他正文保留。见[搜索截图](../assets/hcd-word-long-outline-search-2026-10-28/search.png)和[文件回读](../assets/hcd-word-long-outline-search-2026-10-28/readback.json)。这是本机合成文档，不代表分页、自动更新目录或 Office 桌面验收。

进一步修复匹配词跨越 256 字符显示边界时，虽然搜索成功但片段可能只露出半个词的问题；现在根据完整匹配范围选择片段。16 项大纲和布局专项通过，包含跨边界大小写匹配与表情字符；新增边界尚未单独做浏览器验收。

跨节大纲定位现同时监听协作模型和已挂载编辑器：目标区域仍在挂载或同步时，如果协作者删除或转换该标题，立即提示目标已不存在，不等待编辑器事务，也不按同名标题或旧位置跳转；目标仍存在时继续等待编辑器投影。受控测试使用两个 Yjs 文档，在目标编辑器尚未就绪时由同伴删除标题并插入同名替代标题，验证只提示一次且不误定位。大纲与定位专项 16 项及 TypeScript 检查通过；尚未完成真实双浏览器在挂载时的并发删除验收。

隔离双成员浏览器复验：Alice 从第 1 节搜索并定位到第 2 节末尾标题 `Long outline 180`，实际光标位于该标题，版本仍为 r4。Bob 在另一页面定位该标题并改为正文后，Alice 的搜索结果显示没有匹配标题，正文仍显示原文字与 Bob 的操作标记；Bob 保存 r5 后，实际 DOCX 包回读该文字为普通段落。[协同界面](../assets/hcd-word-outline-peer-2026-10-28/converted.png)。这是同机隔离服务与合成文档；转换发生在定位完成后，没有复现区域挂载期间删除的精确时序，也不是物理 Word 排版验收。


大纲搜索摘要修正了国际化大小写转换导致的偏移：部分字符小写化后长度会变化，搜索命中位置现在映射回原始标题的 Unicode 字符位置再生成摘要，避免长标题中明明命中却看不到目标词。专项测试覆盖重复 `İ`、长标题和 emoji 边界；该改动不改变文档内容或大纲定位身份，也不代表已完成正文分段加载或所有复杂脚本验收。
