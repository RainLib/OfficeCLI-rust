## 请求和房间约束

`POST /v1/documents/{id}/collaboration/word-active-link-{preview|submit|status|cancel|check}` 只在区域 Word `/2` 显式启用后可用。请求需当前文档权限、epoch 和明确的节点/区域/布局/链接版本；`status` 允许读成员，其他动作要求原请求的可写成员。状态只返回确切轮次，不暴露请求或作者。预检/状态输入上限 8 KiB，其他输入上限 256 KiB，读取限时 15 秒；原生核对读取有 30 秒及 16 MiB 上限。

预检返回完整 `pending`（其中 `reviewHash` 是原生摘要），以及独立的活动审阅摘要。提交必须保留二者，不能以活动摘要替代原生签名字段。解析固定作者及代次并规范 JSON 键顺序；预检构造作者字段也使用固定顺序，避免同一请求因键顺序变化被误判过期。

活动链接具有独立 `link` 状态和 `word-story-link` 门禁身份，不复用页面或创建独立区域的请求编号。成员须明确声明 `hcdWordLink=1`，仍需原有的停写协议；目前普通编辑页尚不声明该能力，因此有旧窗口在线时拒绝链接，不能强行切换。测试中显式声明能力的 Socket 客户端只证明服务链路，不能充当原窗口自动桥接的验收。

顺序为：

1. 检查全部在线成员兼容性并请求暂停、设备落盘和网络排空。
2. 关闭连接/包准入，排空并持有旧协调器；重新核对原活动审阅、原生预检及受影响的两个区域。双方页眉页脚的文字、图片意图或上传任务未完成时拒绝；无关正文草稿可保留。
3. 将确切原请求写入版本 5 签名日志后才发送。可能已经发布的准备错误或原生成功丢响应会保持房间冻结；同一请求从保留阶段继续，不能换编号或释放旧房间。
4. 核验固定版本原生签名、目录及内容不变的绑定转换，专用提升后，以同一门禁身份退役原宿主、安装候选并启用普通保存。
5. 成功的原请求重放仍返回原链接版本，不因后续正文保存回退 head。未准备取消同时密封签名日志与原生编号；已准备或结果未知时不能当作取消成功。

侧车进程局部缓存丢失时，`check` 通过当前已加载房间的已知签名链和原生固定版本证明核对原请求，不重新加载共享日志、不替换当前内容、不增加版本。它只适用于已经提升并安装的活动房间；**未完成版本 5 日志在侧车重启后仍须停止协调器恢复，普通恢复 HTTP/UI 的链接接线尚未完成**。历史 head 已前进时的私有草稿比较/合并仍是后续工作。

## 实际验证

- 前端完整 **1933 项**通过，TypeScript、standalone/embed 构建通过；第三方 `use client` 和大包提示仍存在。新解析/阶段/回执/转换及 HTTP 分派测试覆盖身份、键顺序、过期审阅、受影响草稿、迟到变化、成员撤权、旧客户端、保留阶段和丢响应。
- 两套隔离真实原生/侧车及三个 Socket 角色均完成 r1 → 链接 r2 → 双方草稿保存 r3 → 侧车重启、确切回执核对及继续保存 r4。
- 第一套在侧车已成功安装后断开最终响应；原请求重试返回 r2，之后仍只存在一个原生链接提交。
- 第二套增加独立 loopback TCP 代理，在原生链接提交 r2 后接收完整成功响应并断开连接。侧车返回结果未知并保持原轮次 pending；确切重试核对签名、完成原房间替换；随后再丢最终成功响应，仍以同一原请求完成。实际历史只含一个链接版本。
- 两套均验证未准备取消及重试、只读提交拒绝、旧成员拒绝、修改审阅/候选拒绝、其他成员不能重放作者请求。新会话手动加入替换房间，双方正文草稿保留；未验原窗口个人历史或自动桥接。
- r2/r3/r4 的实际语义 DOCX 回读验证目标节不再有对应直接引用、三处文字仅在预期版本出现、原图片字节保留；HCDZ 解包逐版本核对 r1–r4，区域目录保留，只有指定绑定改变，规范/离线校验通过。
- 普通编辑页在服务完成后作为新会话打开 r4，切至第二节“奇偶页不同”，实际显示继承的 `Even header`。截图只证明新会话读取及现有编辑页呈现，不证明正常链接按钮、确认流程或跨设备操作。

## 复现

```bash
python3 scripts/hcd-word-layout-browser.py --clean --story-source --link-source --allow-restart
# 以下 ROOT 使用夹具输出的隔离路径；OUT 使用新的目录。
node --import ./examples/hdoc/editor/node_modules/tsx/dist/loader.mjs scripts/hcd-word-active-link-submit.mts ROOT OUT
python3 scripts/hcd-word-active-link-files.py ROOT OUT
# 另起一套夹具，增加 --drop-native-link-response，复验原生成功丢响应。
```

原生丢响应开关默认关闭，代理只绑定 loopback、只丢自己夹具的一次成功链接响应；不是应用接口或生产故障开关。结束后关闭自建浏览器页，停止自有夹具父进程并确认子进程终止，再移除私有根。令牌、密钥及完整私有日志不进入证据归档。
