# HCD 语义块结构协同修复

状态：替换原型 v3 的嵌套存储、编辑器绑定、光标插件和保存适配已有自动化证据；默认 App 已协商并切换到结构绑定，sidecar 可保留脏正文完成迁移；基础浏览器链路已有验证，复杂结构与旧代离线恢复仍未整体完成。不能把本文件作为上线验收。

## 已确认的缺陷

旧 Word 绑定使用 `default` XmlFragment 和 Tiptap 的 Yjs 绑定。已用实际命令事务和已安装的绑定复现：A 下移第一段，B 在未收到移动的副本中给第一段追加文字；交换更新后新增文字消失。B 编辑第二段的对照组则保留文字。根块移动会重新建立被移动块的底层类型，逻辑 ID 相同不足以保护离线输入。

此前浏览器、保存重开和实际文件验证证明了顺序操作链路，不能覆盖上述离线分支。默认页面已切换到永久载体绑定；旧模式对照保留用于复现这个缺陷。

## 替换原型 v3 数据模型

实现位于 `examples/hdoc/editor/src/semanticBlockStore.ts` 与 `semanticInlineContent.ts`。这是内部协同模型，尚非开放的节点 SDK。

| 数据 | 作用 |
|---|---|
| `hcd-semantic-blocks/3/meta` | 版本 3 与预分配的共享空段落键；只允许显式初始化 |
| `.../content` | 每个图节点分配永久载体；文字分段可引用原有其他载体，正文只存一份，空正文也保留对象 |
| `.../order`、`.../children` | 根顺序和各容器的子节点引用序列；重排不搬迁文字载体 |
| `.../placement` | 每个节点采用的 `{parent, reference}`；并发转换/移动只选一个归属 |
| `.../visibility` | 删除状态独立于位置；并发移动和输入不会自动复活已删除节点 |
| `.../kinds`、`.../attributes`、`.../inline` | 节点类型、属性与是否文字块；递归投影时验证 schema |
| `.../owners` | 图节点到规范块所有者 token 的映射；所有者与容器节点身份分开 |
| `.../canonical` | 所有者 token 到服务端 blockId；已被规范保存吸收的身份置 null，恢复后先用临时 ID 再保存 |

内部 `hcdStructureKey` 标记永久图节点，`hcdCanonicalKey` 标记规范所有者，均不输出到 HTML。引用/列表包裹保留子段落及文字的物理身份，仅改变父子关系和规范身份归属；还原为段落也不复制文字。保存回执按捕获的所有者及永久文字目标处理，因此回执迟到时不把已还原的正文换回旧容器。

新增 `semanticTextFlow.ts`：文字仍只存在原来的永久载体中，`hcd-text-flow/1/segments` 保存稳定分段与边界，`links/order` 保存分段间的连接。拆分向原载体插入内部边界，合并连接已有文字流；内部边界不进入 PM 正文、HTML、规范快照和导出。一个显示段落可以包含多个载体，一个载体也可被拆为多个显示段落。自己的撤销移除边界/连接，保留同伴后续文字；同伴已连接到被撤销边界的续段会解析回仍存活的区间。

重叠合并采用连接继承；相反方向的并发合并可形成环，文字流按稳定键断开一条连接，在确定性投影中保留所有分段，不删除原数据。它与块父子图的非法环不同：块父子环仍拒绝投影。相对选区记录实际载体位置，因此可跨合并/拆分定位。并发拆分按文字边界排序；手动移动/插入绑定目标当时的位置引用，避免拖走后来独立移动的目标或原段落的其他拆分结果。

PM 绑定区分边界合并、开放切片拆分/粘贴和显式块删除。多段代码转换、跨段选区替换、空段合并、普通 Enter 与多段粘贴已有用例。独立复制保留独立载体，不当成拆分。投影在事务外复用同一文档版本的文字流布局；事务中的直接修改不复用缓存。这只处理重复扫描，不证明长文 DOM 懒加载和容量验收完成。

空段转成分隔线/容器后若收到旧载体的离线新字，拒绝不兼容的投影并保留原始文字，不允许保存出丢字版本。该冲突的实际页面恢复入口仍待完成；复杂嵌套边界、混合结构事务和未知格式的冲突处理也仍需扩展。

格式只写实际变化的字段。文字差异按 Unicode 码点比较、UTF-16 长度寻址；连续插入先作为完整字符串插入，再设置各段格式，避免不同来源标记把同一次追加拆成逐字竞争。支持已有 mark 和 hardBreak 等叶子行内对象；带子树的行内扩展仍需后续 codec。

复制分配新图身份和所有者，并清理旧来源信息；内容分配属于系统事务，编辑、位置和可见性属于用户事务。撤销新增/复制只隐藏节点，保留同伴内容供重做。规范回执不进入用户撤销。人员 occurrence 复制规则尚待 D/E 接入。

`reconcile` 在修改前验证完整快照，单次命令的结构、文字和删除合为一次动作。移动/删除命令分别提供临时意图元数据，避免把邻居位移误记为本人移动，或把跨载体合并误当普通删除。该元数据不进入规范正文。

仅失去全部子节点且不再满足 schema 的空包装容器可从投影中省略。非空 schema 错误、环、未知节点/mark/属性和规范身份冲突均拒绝投影，保留原始 CRDT，不调用删除未知类型的修复器。全部内容消失时复用预分配的同一个空段落，避免两端各造空块。未知扩展的只读呈现、导出报告和 SDK 仍未完成。

初始化会拒绝已有旧 `default` 正文或 v1/v2 原型数据，不静默覆盖。此本地检查不是分布式租约，也不是旧房间/旧原型的迁移工具。

## 编辑器、保存与协作光标

`semanticStructureBinding.ts` 和 `semanticStructureIdentity.ts` 仅由新模式显式选用，按全部块后代的稳定键发布事务。复制/粘贴不继承结构身份，拆分分配新键；远端变化使用最小文档替换并恢复相对选区。只读和不能安全表达的转换在接受事务前拒绝，暂存命令检查事务是否被接受。

`semanticStructureSelection.ts` 将文字位置绑定到最深文字块的永久 `Y.XmlText`，NodeSelection 绑定图节点键；光标可随段落进入引用或列表。`semanticStructureCarets.ts` 提供 Awareness 相对选区、范围高亮、节点选择和光标装饰，过滤无效/越界位置及用户显示字段，失焦清理；不写正文。`semanticStructureCollaboration.ts` 提供可选 Tiptap 组合入口，但不初始化或迁移房间，也未替代 App 的历史管理。

保存协调器通过显式 `structure` 选项统一读取逻辑投影、摘要、捕获目标和签名回执。`semanticStructureSources.ts` 按所有者更新规范 ID，并退休已从该次规范快照移除的 ID；永久文字不重建。隐藏节点、迟到回执、保存中继续输入及丢响应恢复已有测试。未选结构适配的当前协调器拒绝 v1/v2/v3 结构或未协商的文字流数据，此检查不能防住更早部署的客户端，仍须服务端协议限制。

## 原生协议与迁移提交

原生 API 已补 `collaborationProtocol`、epoch/协议联合校验和受信任保存服务的迁移 CAS。转换后的状态先持久化，再发布新代描述符；旧状态保留恢复副本，原迁移 ID 的精确重试不会覆盖后续输入，未激活文件不会被下一次 reset 误用。118 项原生单元测试、构建、Clippy 和格式检查通过；HTTP 探针完成干净旧 Yjs 状态迁移、旧/错协议拒绝、重试保护及 18 个导出文件回读。PostgreSQL 路径已实现并编译，未进行真实数据库验收。

sidecar 现已接入显式协商、完整消息排空、未保存正文与图片候选转换、作者账本、持久 journal 和未知回执重试。真实双 socket 与 sidecar 重启验证通过，包括规范保存已提交但回执丢失时不重复提交；四个实际文件回读通过。默认页面尚未调用协商，旧设备缓存、上传中资源交接和 UI 恢复仍待接入。接口与边界见 [协议与迁移提交](hcd-collaboration-protocol.zh.md)。

## 剩余实施顺序与门槛

1. **文字归属剩余范围**：基础跨段合并、多段代码、拆分与多段粘贴已接入替换模型；继续复杂嵌套/表格/跨节、多步混合事务、非文字转换中迟到输入的冲突恢复与格式兼容，不能把当前用例推导为所有结构编辑完成。
2. **真实编辑器**：补真实 DOM/IME、粘贴、选区、协作装饰及转换中输入验收；复杂嵌套/表格/跨节、拖拽自动滚动和长文容量仍需专项。
3. **协议与迁移**：原生协议限制、单 sidecar 消息排空、脏草稿/图片候选、持久任务与未知保存确认已有本地 socket/API 证据；继续默认页协商、旧页面上传与本机未发送操作交接、旧代设备草稿语义恢复及冲突界面。持久化成功才接纳新房间，旧客户端不得混写；失败保留原 room/bundle/草稿。不得同时维护两个规范正文。
4. **历史与资源**：接入已有文字/图片时间线，验证只撤销本人动作；设计 inactive 引用、隐藏载体与历史/离线草稿的安全回收。
5. **默认页面切换及端到端验收**：上述通过后切换 App；用真实双会话离线/重连、撤权/过期连接、保存重开和实际导出复验。默认页面缺陷在此之前仍未修复。
6. **后续原范围**：继续服务端 `@人员` 目录、解析、ACL、稳定 occurrence 和已提交关联查询；完成节点 SDK、通用 AI 建议/接受/撤销与补全、跨格式适配及导出能力报告。管理平台、字体后台和实际提醒发送继续后置，提醒只预留事件契约。
