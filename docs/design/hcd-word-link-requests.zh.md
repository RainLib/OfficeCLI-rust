# Word 正常链接操作、影响确认与持久原请求

后续页面原请求已迁入 IndexedDB，关闭重开、旧标签页队列迁移与取消恢复的当前状态见[页面设备请求](hcd-word-page-device.zh.md)。下文保留该批历史边界。

2026-10-30。在[链接后的原窗口接续](hcd-word-link-session.zh.md)基础上，普通区域 Word `/2` 的插入操作区和统一命令面板现提供“页眉链接前一节”“页脚链接前一节”。这次接通正常创建入口、确认、本机完整原请求和恢复核对，不再需要用脚本发起用户链接。旧协议不自动迁移；其他格式、管理平台与提醒范围保持。

## 用户操作与请求约束

- 第一节和已经继承的对应页类型不可再次链接；页眉、页脚及首页/默认/偶数页分别判定。页面设置、独立区域创建和链接在当前请求未结束时互相禁用，服务端仍独立执行权限、版本和房间门禁。
- 预览前经过原附件协调锁与正常保存，预览自身不发布链接。确认显示节、区域和页类型、实际继承来源节、可见内容是否改变、原独立内容仍保留、固定基准版本，以及共享内容之后的修改范围。没有前节对应区域时明确说明可见区域将为空。
- 可见内容受影响的节按每批 20 项展示，覆盖全部列表，不为大文档一次挂载全部 DOM。可见内容不变的链接仍是一项绑定修改；已有个人内容历史保留，但链接结构自身暂不支持通过文字撤销恢复。
- 确认时重新核对原房间、版本、布局和文件任务。完整已审阅请求先写入 IndexedDB，再允许第一次发送。按成员、文档、服务地址和协议隔离；事务 CAS 阻止同源窗口覆盖另一请求。存储失败不发送，未知结果不能直接删除原请求。
- 原请求包含 native transaction、完整 pending、两级 review hash、候选布局和确认摘要，不包含会话令牌、原生签名密钥或共享日志。浏览器/服务共用安全解析；Node 签名逻辑不引入浏览器包。
- 关闭后重开使用原请求；状态缓存丢失时走原生固定版本签名核对，不重发写操作，不把历史链接基线安装为当前版本。自动核对等待正常房间就绪；兼容性恢复页仍可由用户明确进入。
- 取消先持久化取消意图，仅对服务端确认未准备的原编号取消；结果不明继续核对原取消。确认安装或取消后，用户明确关闭才移除设备请求。损坏、旧 epoch 或身份不符的原记录保留下载，不擅自替换。

## 本机实际浏览器与文件证据

使用独立原生服务、真实侧车、透明 loopback 故障代理及三名普通嵌入页。浏览器输入与按钮均通过 CUA，脚本只负责夹具、网络故障及实际文件回读，没有通过脚本改写浏览器应用模型。

1. Alice 正文输入先由正常链接入口保存为 r2。第二节偶数页页眉预览显示第一节来源；取消预览不生成链接版本。
2. 再次预览后，Bob 在同一正文段落输入迟到内容。Alice 从正常确认按钮发起链接 r3；三个原页面 frame/loader 未变化，双方内容保留，只读成员仍不可编辑。
3. 代理收到完整成功响应后丢弃。浏览器自动重发了一次相同 POST；记录核对两次完整请求相同、都返回原 r3，只存在一个链接版本。不能将它描述为“只有一次网络请求”或“用户手动重试”。迟到正文随后正常保存 r4。
4. 下载完整原请求后关闭 Alice 标签页、重启侧车并重开。固定版本核对确认原 r3，同时当前正文仍为 r4；再次下载原请求与第一次逐字节相同。初次核对早于房间就绪时曾失败，已移至正常房间就绪后触发，并在显式重新打开流程中复验。
5. 第二节首页页脚的正常预览明确说明前节内容不存在。Bob 在预览后编辑此页脚；提交因 `word-story-source-draft-pending` 拒绝，原请求及输入都保留。用户在正常请求面板取消未准备操作，随后页脚输入正常保存为 r5，独立绑定未被删除。
6. 再次侧车重启后，对同一取消请求发起迟到重放，原生持久取消记录拒绝，head 仍为 r5。**本批取消 UI 的成功证据发生在重启前；未把导航完成前读取到的旧弹窗当作重启后 UI 验收。** 原生重放会因进程缓存是否存在返回 `word-topology-cancelled` 或 `word-active-link-cancelled`，都不能继续执行。
7. 正常页下载 `/6` 设备备份后，独立读取核对双方正文、被保护的页脚文字和两处绑定。该备份下载时没有待提交增量，不代表本批覆盖了未持久化设备缓冲或系统断电。

实际 DOCX r3/r5 检查页眉继承关系、未取消的独立页脚、文字及原图片字节；r5 DOCX 再导入并校验。HCDZ 解包逐版本对照 r1–r5，规范与离线包均校验通过。原独立页眉 story 全程不变。完整记录见[文件回读](../assets/hcd-word-link-requests-2026-10-30/file-readback.json)、[浏览器范围](../assets/hcd-word-link-requests-2026-10-30/browser.json)和[请求记录](../assets/hcd-word-link-requests-2026-10-30/requests.json)。

## 继续开放的范围

正常链接入口完成不等于 Word 或整体目标完成。仍包括：历史私有草稿比较/合并及携带恢复包；结构/页面字段自身历史；页面请求关闭标签页后的持久化统一（页面现仍采用 sessionStorage，story/link 已使用 IndexedDB）；复杂独立区域复制与文件任务；原稿保留的链接和内容混合导出；旧协议迁移、精确分页、自动目录和页码、正文分段；PPT/PDF/Excel 深度创作、字体、国际化、真实 AI 和多实例。

本批没有 Rust 修改或原生重建；使用有摘要的既有本机二进制。未重跑 Rust 全工作区或 Clippy，既有 Clippy 失败继续开放。实际浏览器多窗口不等于跨物理设备；服务重启期间部分旧成员曾进入显式重连状态，重新打开普通页后内容完整，本批不声称全部旧窗口可跨进程重启无缝恢复。未进行真实 IME/RTL、PowerPoint/Word/WPS、远端存储或生产验收。运行时私有根在停止本批进程后移除，凭证与完整签名日志不归档。
