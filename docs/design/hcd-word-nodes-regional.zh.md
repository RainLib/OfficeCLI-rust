# Word 区域自定义节点、资源与富文本块

2026-10-27。显式 `hcd-word-regions/1` 编辑器现在接通既有 `nodeExtensions` 注册接口，支持行内原子节点、块节点和 `contentModel: 'blocks'` 的可编辑子块。管理平台和提醒投递继续暂缓；不会自动迁移旧文档或启用未来的行内容器模型。

## 已接入

- 宿主注册的节点出现在功能区、右键、`/`、块旁插入菜单和命令面板，继续共用命令 ID、翻译、图标、状态及执行逻辑。
- 可在正文、页眉、页脚的对应编辑器中插入节点。右侧属性面板使用已有数据校验、属性、显式迁移和资源接口。
- 行内节点保存稳定实例 ID；块节点可保存业务属性、资源和各格式的可读快照；富文本块内部使用正常段落、标题和内联格式，不把子内容压成一段回退文字。
- 属性修改继续使用字段意图。不同字段并发合并；同字段保留全部候选，阻止保存，右侧支持定位节点并明确选择。个人撤销可恢复候选，重做恢复选择。
- 资源归档通过原生受权接口完成，节点仅保存名称、类型、字节数和内容摘要，不保存临时 URL。属性页可下载资源或移除引用。
- 本窗口资源请求期间不会显示“已保存”，保存、关闭和导出复用同一门禁。资源或图片选择若在一个保存请求发出后才开始，该请求的旧回执仍不能授权关闭。
- 未加载扩展的写成员保留原始业务数据和可读内容，只读展示相关节点；仍可编辑普通正文。富文本块的子编辑区域也会只读，删除保护沿现有事务过滤和历史检查执行。
- 节点视图跟随当前语言刷新；缺扩展说明不再固定为英文。动态生成的节点菜单检查底层插入动作，避免显示可点但执行时才失败。块旁插入使用经过块边界校验的位置，不替换受保护节点。

## 宿主扩展接口

无需另建区域 SDK：

```tsx
<EmbeddedHcdEditor
  {...documentConnection}
  nodeExtensions={{nodes: myNodeDefinitions}}
/>
```

注册定义继续使用 `type`、`version`、`display`、数据校验、`fallback`、`properties`、`exportAdapters`、可选资源以及显式迁移步骤。富文本块声明 `contentModel: 'blocks'`；其导出快照需要 `includeContent: true`，保留真实子内容。

完整示例见 `examples/hdoc/editor/src/examples/regionalNodes.ts`：状态标签、资料卡片和说明块。这些示例只由明确的示例宿主注册，没有加入默认产品菜单，也没有引入可执行的文档脚本。

区域的自定义行内标记菜单尚未开放；未来 `hcd.extension/3` 行内容器仍被 wire7 房间明确拒绝。这与本轮行内原子节点和富文本块是不同能力。

## 保存与回执修复

区域协调器原本已使用 `businessDraftProblem` 阻止节点冲突和未完成的属性合成。本轮额外将节点意图、合成结果、引用及删除审阅元数据纳入精确作者观察值；业务元数据即使没有改变可读文字，也不能通过后来的合法输入补出错误作者归属。浏览器在收到下一条状态回执前也能识别本地业务冲突。

真实资源节点首次提交暴露了一个回执差异：新块节点回退文字没有显式布尔格式值，原生投影补全了 `false`。原生已提交 r3，但协调器正确拦住“已保存”。修复包括：

1. 新块节点从创建时便携带与原生一致的六个布尔默认值。
2. `wordReceiptContents` 只允许块原子节点回退文字中“缺失”和 `false` 的等价，不改变冻结的签名请求、原 requestId 或原 digest。文字、真实格式、资源及业务载荷差异仍拒绝。
3. 接收经过签名记录及不可变投影核验的结果后，只补缺失默认值，保留保存期间的新输入，并以规范投影摘要作为下一次基线。
4. 业务元数据未受权变更不会因为确认回执而获得作者绑定。

实际停止并恢复自有服务后，原 r3 请求核对成功，没有新增版本，节点及资源完整。修复前后快照和截图保留在证据目录。
