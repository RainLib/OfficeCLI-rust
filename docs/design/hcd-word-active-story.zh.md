# Word 活动房间的独立页眉页脚预检

日期：2026-10-30。本文记录只读预检的范围；后续实际侧车已接活动提交、确切轮次与房间安装，详见[活动事务与验收](hcd-word-active-story-submit.zh.md)。正常创建确认与自动 story 桥接仍未开放。管理平台与提醒发送不实施。

## 当前能力

`POST /v1/documents/{id}/collaboration/word-active-story-preview` 要求显式启用布局感知区域房间、当前写权限、稳定人员身份及区域 2/布局 1/节点 7 声明。输入严格限定为 `epoch` 和 `selection`，选择包含节 ID、页眉/页脚、首页/默认/偶数页变体及原事务编号；不接受客户端指定操作人。

预检绑定当前 owner、租约、版本与布局摘要。已独立的直接绑定不能被覆盖；没有直接绑定时，按同一变体找到上一节的实际继承来源，并计算到下一个独立绑定之前的受影响节。不存在继承来源时规划空白区域。

原生服务从匹配的原 DOCX 生成候选，返回候选承诺、复制内容和明确的引用复制选择。侧车核对不可变版本、候选区域、继承来源与影响范围；超过 900 KiB 的待准备内容拒绝，未知扩展复制仍拒绝，不把图片等不支持复制的对象静态化后冒充完整独立区域。

响应是 `hcd-word-story-preview/1`，包括原选择、审阅摘要、完整 `pending` 和影响摘要。审阅摘要绑定文档、epoch、签名日志 lineage、规范根及完整候选摘要，重复预览相同基准和编号可得到相同结果。候选仅留在请求返回值中，目前还未形成正常浏览器持久请求；单独的活动提交 API 见后续事务说明。

## 协作和草稿保护

- 预检不请求成员停写，不重载活动 owner 共用的签名日志，也不初始化或追加日志。整个读取持有普通请求门禁，结构替换须等待该读取退出。
- 读取前后核对租约、owner、版本、布局和操作人的当前权限。规范版本或来源变化后拒绝旧预览，不能把读取成功当作后续提交保证。
- 继承来源的规范文字、富文本、图片意图和上传任务与当前活动模型对照。来源有未保存变化时返回 `word-story-source-draft-pending`；来源在原生预检期间出现修改也拒绝该预览。
- 其他正文区域的普通草稿不会被清除或复制到新 story；不相交的迟到正文输入可以保留。已取消编号被拒绝。
- 不支持复制时返回受控错误；原生响应、凭证、异常栈和未经限制的错误消息不直接返回用户。

## 验证

完整前端 1879 项及新增 5 项预检专项通过，TypeScript、独立版和嵌入版构建通过。新增专项覆盖重复结果、禁止活动日志重载、不相交正文草稿、来源未保存和迟到变化、版本/权限变化、取消编号、错误候选范围及未知扩展拒绝。

隔离 Chrome 三角色连接实际侧车和原生服务：继承默认页脚、空白偶数页页脚均可预览；重复请求不增加规范版本；只读 403、旧模型 426、已独立区域和不支持复制的图片页眉被拒绝。正文草稿经预览后继续保存 r2；未保存继承页脚被拦截，保存后 r3 可重新预览，三角色均确认到 r3。[浏览器/API 证据](../assets/hcd-word-active-story-preview-2026-10-30/browser.json)

实际 DOCX 中正文和页脚修改各一次；HCDZ 固定 r3 打包，r1–r3 解包投影一致，所有 story 及节布局不变，原 DOCX 摘要不变，预览候选未安装。[文件回读](../assets/hcd-word-active-story-preview-2026-10-30/file-readback.json)及[验证清单](../assets/hcd-word-active-story-preview-2026-10-30/validation.json)

首轮脚本因两端查看不同的首页/默认页变体而无法在同伴页面找到页脚标记；修正测试视图后通过。受控连续输入仅用于保留待保存来源，不能计为真实输入法或网络故障验收。未重建原生二进制、未重跑 Rust 全工作区或 Clippy，没有真实设备、外部 Office、多实例或生产验收。
