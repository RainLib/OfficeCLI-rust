# OfficeCLI 图片预览与编辑设计

使用本机 Pen 应用的 MCP，在 [officecli-workspace-v2.pen](../officecli-workspace-v2.pen) 中补充了图片工作空间。画布章节名为「图片，也是一份可协作的文档。」及「换格式，或只重绘你选中的部分。」，包含 34–48 共 15 个页面状态。

这次交付是设计稿、设计素材和交互约定。独立图片的导入、编辑、导出与协作运行能力仍需按设计接入编辑器；页面中的处理进度、文件信息和团队数量属于示例状态。

## 格式转换与局部重绘补充

### 格式转换：独立入口和明确结果

原图预览工具栏增加「转换格式」，直接进入 44 页，无需先进入编辑。44 页展示 `PNG → WebP`，可以切换 PNG、JPEG、WebP，并选择转换原图或当前编辑版本。目标格式改变时同步更新扩展名、可用参数及输出提示。

- PNG 隐藏有损画质滑杆，保留透明设置；JPEG 显示画质与透明背景填充颜色；WebP 展示画质与透明选项。JPEG 的背景设置视觉参见 43 页。
- 转换执行真实解码和重新编码，完成后核对实际 MIME、编码格式、输出尺寸和解码结果，不能只修改扩展名。格式能力由后端编码器返回；不可用格式不作为可执行选项。
- 预计体积与实际体积区分；45 页的大小与格式必须来自成功生成的输出文件。失败时保留源文件与设置，允许重新转换；取消时清理临时输出，不发布半成品。
- 默认另存副本，转换成功后提供「下载」和「在新标签打开」。新标签有独立的缩放、平移、编辑历史和 AI 会话；原文档不被替换。

### 局部重绘：选择区域、描述、生成、对比

统一 AI 页面工具栏增加「局部重绘」入口，对应 46–48 页。

1. 在 46 页涂抹需要修改的位置，可擦除、撤销或清空蒙版，调整画笔大小和羽化。示例按实际花瓶轮廓覆盖柔和紫色蒙版，不出现矩形选中框。
2. 输入「将花瓶的陶土橙釉改为鼠尾草绿釉，保留瓶型、花纹、反光与人物。」；确认「只修改涂抹区域」，选择图像模型和协作数量。空蒙版、空提示词或图像能力不可用时禁止生成，并在相邻位置说明原因。
3. 47 页在同一花瓶蒙版内显示 GLSL 流光，保持图片和文档尺寸。读取蒙版、生成与边界检查分别展示归属和状态；指针只显示名字，任务进度在侧栏。
4. 48 页对比原图橙色花瓶与绿色候选，人物、背景及蒙版外区域保持原样。支持查看蒙版、继续局部重绘、丢弃和应用；应用前校验来源版本。

蒙版使用原图像素或归一化坐标；浏览缩放、拖动画布、滚动以及侧栏收起均只改变视图。裁剪或旋转改变图像坐标后必须同步变换蒙版并重新校验。生成结果按蒙版及羽化权重合成回原图，不能把整个生成图直接覆盖到画布。

写锁覆盖蒙版及羽化影响范围，重叠写入排队。执行中的 Agent 持锁，边界检查等待候选；完成、取消、失败和租约超时释放锁。原图、蒙版、提示词及来源修订属于共享任务内容，未提交候选不会覆盖其他人的修改。

## 视觉与布局

- 复用现有 `$canvas`、`$surface`、`$ink`、`$accent` 等明暗主题变量。统一大背景，外层工作区域使用圆角，实际图片不增加卡片、内边距、圆角或常驻选框。
- 复用多文档标签、导航、状态栏和统一 AI 抽屉 `AUmlC`。图片与 DOCX、XLSX、PPTX 等标签并列，每份文档独立保存视图、编辑草稿、候选、会话和协作状态。
- 右侧面板从「导出」之后的入口恢复；收起时释放全部宽度。移动端使用可收起底部抽屉。
- 工具、进度和操作按钮位于画布外。手动裁剪模式显示网格和手柄；AI 操作使用柔和蒙版与名字指针。

## 编辑与版本交互约定

1. 打开图片先显示可用原图；保留 EXIF 方向校正后的像素坐标与源文件引用。进入编辑沿用同一图片节点和视图。
2. 裁剪、旋转、翻转、尺寸和调色作为可撤销的编辑参数保存。预览调整只更新图片变换或渲染结果；应用后形成一个版本，原图始终保留。
3. AI 的操作范围必须明确为整图或局部蒙版。规划模型显示 `gpt-6.1-sol`；实际修图或生成调用独立图像模型，其选择与错误状态独立展示。
4. AI 先生成候选，再进入对比。候选未应用时不改写当前版本。应用时检查来源版本；版本已变化时要求基于最新版本重做或保留候选为副本，避免覆盖其他人的修改。
5. 对比分割线可拖动，两侧使用同一尺寸、缩放和视口；支持按住查看原图。应用、丢弃与继续调整均保留清晰入口。
6. 局部重绘的独立流程见 46–48 页。其他 AI 工具可扩展为移除背景、替换背景、扩图与生成变体；工具可用性由服务端能力返回。不可用时展示具体原因和可继续操作的入口。

## 画布与动画约定

- 滚轮缩放只影响当前图片画布，以鼠标位置为缩放锚点；空格拖动、双击适合窗口。移动端双指缩放和拖动平移。切换标签与收起面板保留各自视口。
- Agent 指针属于图片的像素坐标层，和图片共用缩放、平移、滚动变换。标签仅显示 Agent 名称，状态在侧栏显示。
- 指针从 `from` 到 `to` 沿短贝塞尔曲线插值，参考时长 180–480 ms。新位置到来时从当前显示位置继续；离开文档或步骤结束后淡出。跨文档操作不在错误标签上显示指针。
- 生成区域尺寸固定。局部蒙版使用 [generation-mask.glsl](assets/generation-mask.glsl) 的缓慢流光，只更新对应图像区域；任务完成后淡入候选，不重挂载页面、不重置滚动位置。
- 系统偏好减少动态效果时，改为静态低透明蒙版与无移动过渡的指针。动画取消、失败、面板切换均不得残留覆盖层。

## 多 Agent 协作约定

- 协作数量可以设置；调整数量影响未分配工作，不中断已取得锁的操作。读取和核对可并行；重叠区域的写入按顺序执行。
- 锁作用于文档、源修订版本和归一化像素区域。整图调色、旋转、裁剪等影响全图的操作取得全图锁，不能与其他写入同时提交。
- 区域占用显示持有者及「等待区域 / 编辑其他区域」入口，区别于权限拒绝、参数错误或版本冲突。等待中的 Agent 不显示为已执行成功。
- 锁包含所有者、租约期限与心跳；完成、取消、异常和断连均释放或过期，重试使用新的修订校验。释放必须核对所有者，避免旧请求释放后来获得的锁。
- 团队共享原图引用、蒙版、任务方案和候选版本。候选带上来源修订、操作区域和作者；应用时做版本检查，禁止后提交者覆盖已提交修改。
- 取消或失败停止生成反馈、清理指针并释放锁；保留可用候选与会话，允许重试。

## 格式与导出约定

| 格式 | 设计中的编辑与导出行为 |
| --- | --- |
| PNG | 基础编辑、AI 候选与透明区域保留；显示尺寸和透明选项，隐藏有损画质滑杆 |
| JPEG | 基础编辑与 AI 候选；显示画质与透明背景填充颜色 |
| WebP | 基础编辑与 AI 候选；支持画质与透明区域选项 |
| 动态 GIF / 动态 WebP | 动画预览、暂停和逐帧定位；静态编辑需明确选择「编辑当前帧」，不得静默丢失动画 |
| SVG / 其他图片格式 | 根据真实解码与导出能力展示入口；矢量编辑、栅格化或格式转换需明确区分，不宣称所有格式均可无损编辑 |

导出选项来自当前图片的能力信息。尺寸修改保持比例时同步另一维，JPEG 处理透明背景后再编码。默认另存副本；文件名、扩展名和实际编码格式保持一致。

- 局部重绘使用 [花瓶蒙版](assets/vase-repaint-mask.png)、[局部流光着色器](assets/inpaint-mask.glsl) 和[局部合成候选示意](assets/vase-repaint-candidate-demo.png)。候选通过同一蒙版内的颜色合成制作，用于说明交互，不代表已接入实际 AI 生成；蒙版透明区域的像素与原图一致。
- Pen 换背景请求因生成额度进入等待状态，保留在 36 页的禁用图层「设计素材 / Pen 换背景待生成（额度等待）」，可在 Pen 中待额度允许后继续。它不参与页面截图或候选效果。
- 通过 Pen MCP 导出并目视检查全部 15 页的原尺寸 PNG；检查文字、按钮、侧栏收起、蒙版轮廓和移动端边界。GLSL 已在 Pen 渲染器中用于设计效果。
- 应用接入后的验收还需覆盖：缩放隔离、撤销与重做、对比同步、AI 取消与失败、锁超时与重连、版本冲突以及导出后的真实文件解码。本次不将这些运行能力计为已实现或已通过测试。
