## 区域 Word 字号增量

普通编辑器和区域 Word 的操作区/属性区通过统一的 `text.fontSize.set` 命令应用字号。输入值须为有效数值，沿用半磅限制；输入草稿绑定原编辑器、文档、选区和当前输入格式，异步操作前目标变化时拒绝应用。个人撤销分组与协作保护沿用各入口的已有机制。

受控测试覆盖字号包中的源身份和格式信息、跨区域个人撤销保留同伴格式、编码后重开，以及只读/未准备/受保护内容的命令门禁。此前本地浏览器观察过正文 19.5 pt、共享页眉 31.5 pt 保存，并在新只读窗口回读；页脚 18.5 pt 应用及撤销也已观察。**页脚最终重做、旧编辑窗口稳定性和这一增量的外部 Word/WPS 排版仍未完成验收。** 不将当时的浏览器观察故障视为通过，也不将其直接归因于已确认的产品缺陷。

## 可复验命令

在仓库根目录运行：

```bash
cargo fmt --all -- --check
cargo test -p hcd-core -p hcd-docx -p hcd-formats -p officecli -p docx-handler -p oxml -p pdf-handler -- --test-threads=2
```

在 `examples/hdoc/editor` 运行：

```bash
npm ci
npx tsc --noEmit
node --import tsx --test --test-concurrency=2 --test-force-exit src/*.test.ts
npm run build
```
