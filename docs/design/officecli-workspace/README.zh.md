# OfficeCLI 文档工作空间设计

通过本机 Pen 应用的 MCP 创建。`../officecli-workspace.pen` 是可编辑的原生图层文件，包含 13 个页面或状态和 1 个设计系统画板。这次交付的是设计稿；动效和交互以下述规范说明，尚未把这套界面移植到实际编辑器。

[页面总览](./overview.png) · [完整 PDF](./officecli-workspace.pdf) · [画板清单](./manifest.json)

## 视觉方向

Quiet Workspace：暖灰画布、白色内容区、深绿主色。减少工具栏和边框的视觉重量，让文档成为主体；文件格式、协作者身份和操作状态使用独立颜色辅助识别。

| 用途 | 变量 |
| --- | --- |
| 画布 / 内容区 | `#F4F5F7` / `#FFFFFF` |
| 正文 / 次要文字 | `#20252B` / `#697480` |
| 主色 / 选中背景 | `#246B59` / `#EAF3EF` |
| 边界线 | `#E8EBEF` |
| DOCX / XLSX / PPTX / PDF | `#4B72B8` / `#27866A` / `#CB8252` / `#BF6265` |
| 界面字体 | Inter、Noto Sans SC |
| 文档正文 / 纯文本 | Noto Serif SC / Noto Sans Mono |

## 面板收起与多文档

- 左侧文档大纲宽 204px，PDF 页面栏 180px，幻灯片栏 188px；收起后使用 44–48px 图标轨道。文档库导航宽 228px，沿用相同收起规则。
- 右侧属性面板宽 244px，协作面板 276px，批注面板 274px；收起后宽 48px。轨道保留恢复、属性、协作、批注和历史入口。
- 上下文工具栏高 46px，可单独收起。专注模式同时收起两侧与工具栏，保留多标签、文件标题、保存状态、模式切换及导出入口。
- 面板使用 200ms ease 过渡。支持 `prefers-reduced-motion`，此时直接切换状态。收起按钮提供名称、提示和 `aria-expanded`；键盘焦点始终可见。
- 以文档 ID 保存模式、面板展开状态、缩放、滚动位置和当前定位；XLSX 额外保存工作表与选区，PPTX/PDF 保存当前页。切换标签恢复各自状态。
- 有未保存修改时，关闭标签提供保存、放弃和取消。协作消息与修订按文档归属显示，后台标签以小圆点提示新活动。

## Agent 移动与操作效果

画板展示定位和冲突的关键状态；以下为实现时的动效规范，并非原稿中已运行的动画。

| 事件 | 画面反馈 | 行为约束 |
| --- | --- | --- |
| Agent 定位或读取 | 目标段落、单元格或形状显示细描边、浅色底和带名字的光标 | 位置必须来自实际文档节点或文本范围 |
| Agent 在同一视口移动 | 光标从上一有效位置平滑移动，建议 160–240ms | 降低动态效果时直接更新；换页时在新目标淡入 |
| Agent 提交修改成功 | 修改区域短暂高亮约 800ms；右侧新增活动及修订记录 | 只有成功提交后才显示“已更新” |
| Agent 提交版本过期 | 显示琥珀色“需要重新读取”，提供“查看最新内容” | 保留已保存内容，重新读取后再提交 |
| Agent 离线或活动过期 | 光标淡出，列表更新状态 | 遵循服务端活动有效期，不持续制造假活动 |
| 点击“定位到内容” | 滚动到对应位置并短暂强调目标 | 由用户触发；远程 Agent 移动不抢走本地视口或焦点 |

本地选区使用绿色，Research Agent 使用紫色，Editor Agent 使用琥珀色；颜色同时配合名字、头像和状态文字。多个 Agent 指向同一区域时合并身份标签，悬停展开。预览页展示远程活动，但本地保持只读。

## 格式与编辑边界

- DOCX 复杂块保留版式并标注只读；进入编辑页不代表所有原始结构都能无损修改。
- XLSX 用格式专属工具替代正文列表工具；预览时公式栏只读，不展示新增工作表入口。
- PPTX 编辑提供位置尺寸与演讲备注，预览只保留浏览所需内容。
- PDF 的当前画板为批注模式；扫描页、复杂对象及原文编辑范围须依据实际后端能力控制。高亮、批注和新增文字应分别标明是否能够写回源文件。
- Markdown 不提供任意字体、字号、下划线和段落对齐等无法按标准 Markdown 保留的格式入口。
- TXT 文本使用一致的字号与等宽字体；界面上的字体和换行设置只控制显示，导出只保留文字和换行。
- HTML 当前画板为经过清理的语义预览；不承诺复现任意网页脚本和浏览器布局。

设计中的示例内容、统计和身份仅用于表达页面效果。格式支持与转换正确性仍应以运行验收记录为依据，不能由设计稿推断。
