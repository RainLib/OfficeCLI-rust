## 本版调整

统一的雾灰背景贯穿应用顶部、四周和面板之间的间隙。白色内容区和抽屉放置在背景之上，用留白、圆角与轻微阴影组织层级。

- 文档工作台：导航和文档库分别成为独立圆角区域，文件列表减少横向分割线，最近文档使用更舒展的缩略图。
- 编辑页：工具栏移入内容舱，大纲、属性、批注和协作面板使用同一套抽屉外观。
- 收起状态：抽屉缩成 52px 宽的短图标坞，保留展开入口；专注模式显示更大的文档区域。
- 顶部：多文档标签改为胶囊形，编辑/预览切换使用内嵌选中态；主要导出按钮使用深色，次要操作降低视觉重量。
- 协作：保留文档内 Agent 定位、活动和冲突提示；修订状态使用颜色、名字和文字共同表达。

## 页面范围

共 13 个页面或状态，另有 1 个设计系统画板：文档工作台、DOCX 编辑、XLSX 编辑、PPTX 编辑、PDF 阅读与批注、Markdown 编辑、HTML 内容预览、TXT 编辑、专注模式、多 Agent 协作与冲突，以及 DOCX / XLSX / PPTX 预览。

每个格式沿用统一外壳并保留专属操作：表格的公式栏和工作表、幻灯片的缩略图和演讲备注、PDF 的批注、纯文本的显示与换行。只读预览不显示写入工具。

## 交互约定

- 抽屉展开、收起使用 200ms ease；降低动态效果时直接切换。图标坞始终保留恢复入口和操作提示。
- 每个文档独立保留面板、模式、定位、缩放和滚动状态，切换标签时恢复。
- Agent 在同一视口内的有效定位变化使用 160–240ms 过渡；提交成功后短暂强调修改区域。远程定位不自动抢走用户焦点。
- 冲突时显示“需要重新读取”及查看最新内容的入口，不把失败提交显示为成功。
- 格式编辑边界、Agent 活动有效期和可访问性要求沿用[上一版交互规范](../officecli-workspace/README.zh.md)。

本次为可编辑的静态设计稿与交互规范，未修改产品前端，也未实现原稿中的运行时动效。格式保真和转换能力仍以实际运行验收为准。
