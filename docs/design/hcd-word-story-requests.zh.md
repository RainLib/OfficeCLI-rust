# Word 独立页眉页脚：正常创建、设备原请求与取消核对

2026-10-30。只针对显式启用的区域 Word `/2`；不迁移旧协议。管理平台和提醒发送仍后置。

## 正常操作

插入操作区与命令面板提供“创建独立页眉/页脚”。按当前节及实际生效的首页、默认页或偶数页操作；本节该变体已有直接绑定时禁用。按钮位于操作区前部，常用窗口尺寸无需滚动工具栏。

先保存当前内容并检查附件任务，再由活动 owner 做只读预检。确认窗口显示节、页面类型、复制继承内容或新建空白、影响节数和基准版本；默认焦点在取消。取消预览不提交、不写入待处理请求。当前无法安全复制的图片、对象、批注/修订等由原生预检拒绝并保留正文。

确认前再次核对权限、版本、布局和附件；先完成设备记录事务，才发送完整原请求。原请求包括候选、作者、审阅摘要与原编号，没有 token。成员停写、签名提交、房间退役/安装及正常视图、内容个人历史和设备日志衔接沿用[活动事务](hcd-word-active-story-submit.zh.md)与[会话桥接](hcd-word-story-session.zh.md)。区域创建本身尚无结构撤销，确认窗口明确说明这一点。

## 设备记录与竞争

`wordStoryRequestStore.ts` 为每个成员/文档/端点提供单独 IndexedDB 记录，写入采用读写事务中的 compare-and-set，避免两个窗口覆盖。记录不随标签页关闭消失；同源窗口只广播变更信号，不广播候选内容。不同用户、端点隔离，旧 epoch 或损坏记录保留为不可直接提交状态，可以下载原请求并进入恢复流程。

关闭组件会停止等待，迟到响应不能改变已卸载控制器的结果；已经持久化的原请求仍在。未知结果不可直接删除或换编号。结果确认完成后，用户关闭请求面板才清除记录。存储不可用时禁用结构创建；不将未落盘的请求发出。受控 IndexedDB 读取事务中止测试确认原请求保留、异常被处理；配额、驱逐、真实断电和不同物理设备仍需独立验收。

## 结果核对与取消

- 新增 `word-active-story-check`：仅原作者的当前写权限可核对；要求活动 owner 已安装对应区域。读取固定基准、规范 revision 和原生签名 story 回执，验证原候选和唯一新增区域。不会重新提交 story、重载活动共享日志或修改规范文档。
- 状态缓存丢失不等于未提交。浏览器使用完整原请求做签名核对；已有后续正文版本时仍核对创建的固定版本。
- `word-active-story-cancel`：先持久化取消意图，服务端复用阶段内核和成员停写，在签名日志与原生记录中封住未准备编号。已准备或结果未知的事务不会被当作可丢弃请求。
- 取消丢响应或进程重启后，继续同一取消。若首轮发生在房间尚未就绪时，“核对结果”也能继续已保留的取消意图；不会退回创建请求。取消已确认后，延迟到达的原提交被拒绝。

## 验证与复现

前端完整 **1902 项**、相关专项 **34 项**、TypeScript 和独立版/嵌入版构建通过。原生使用记录 hash 的既有二进制，没有重建或重跑 Rust 全工作区。第三方 `use client` 和包体积提示仍存在。

[普通 Chrome 全流程](../assets/hcd-word-story-request-2026-10-30/verified-ui/service.json)使用两名可写成员、一名只读成员及真实原生/侧车：预览取消不增版本；成功响应截断后保留完整请求；三窗自动切换；其他成员继续保存；关闭标签页、显式重启侧车后核对原创建回执，无重复创建；新页脚继续共享编辑、保存和下载设备备份。另对未送达的空白偶数页脚请求取消，再次重启/重开核对同一取消，原提交仍被拒绝，规范版本不增加。

[文件回读](../assets/hcd-word-story-request-2026-10-30/verified-ui/service-files.json)核对真实 DOCX 的独立部件关系、原正文、协作者文字与新页脚文字；HCDZ 解包逐版本比较，并按实际成员和端点读取下载的 `/6` 设备备份。[汇总记录](../assets/hcd-word-story-request-2026-10-30/validation.json)包含失败尝试、源码/产物摘要及证据边界。

python3 scripts/hcd-word-layout-browser.py --clean --story-source --allow-restart
