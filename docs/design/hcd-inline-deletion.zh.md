# 行内容器删除审阅与协调恢复（2026-10-27）

本轮承接内部行内正文、签名保存、属性候选，接入可编辑行内容器的删除审阅。默认 schema、公开 SDK、活动 wire7 房间没有启用该节点；管理平台和提醒投递继续后置。

## 实现

`inlineDeletionReview.ts` 复用现有审阅集合，为行内容器增加 version2 回执。回执保留不可变定义、删除前的相对位置、相邻业务节点以及审阅快照；可编辑正文不作为恢复副本写入回执，而是从永久 `Y.XmlText` 正文载体实时投影。快照用于确认用户看过的内容，不能作为另一个可编辑正文。

删除不会销毁正文、子容器、来源默认值或资源。迟到正文、属性、提及和候选变化会改变审阅快照并阻止保存；过期确认没有共享写入副作用。明确保持删除仅确认当前快照，之后到达的编辑仍重新进入审阅。整个外层容器删除只记录该子树；已有子回执在外层仍包含它时由外层审阅覆盖。整块删除同样覆盖仍位于块内的旧行内回执，避免重复列出同一内容。

嵌套容器和内部提及的恢复使用其真实父正文载体及 PM 位置。相邻节点的边界采用实际 `nodeSize`，不会把可编辑容器当作一个 PM 字符。原位置确实失效时才恢复到新的末尾段落。`Transform.insert` 保留父容器结构；整批身份预检阻止把已移动到别处的子节点再复制回来。

恢复复用 `SemanticSaveCoordinator.restoreInline` 的串行队列，并使用相同的显式正文模型。两次针对同一回执的恢复请求只有第一次插入，后一次按已恢复处理。个人撤销/重做继续预检他人的可见字符和属性候选；不允许通过撤销创建或重做删除来隐藏尚未审阅的同伴变化。创建的撤销保留正文载体，并在同一逆向事务中捕获回执，以处理之后才到达的离线输入。

缺少公共行内容器 codec 时，块操作和“保持删除”继续受保护，仍可恢复内容。默认房间显式拒绝只有 version2 回执、没有正文/模型标记的注入；旧原子节点和提及回执保持 version1。

## 实际文件验证发现并修复的来源问题

真实原生服务曾拒绝恢复后的 r10：`replacement source identity does not belong to the changed blocks`。原因是被删除正文在保存捕获前已隐藏，不在 `entry.sourceIds` 中，保存回执未退休其中的旧来源 ID。恢复时这些已被规范版本移除的身份再次提交，触发原生校验。

`reconcileStructureSources` 现在对显式内部模型的全部保留载体，以完整规范响应中的允许 ID 集合退休失效来源绑定。正文、样式和协同字符保留；仍属于规范响应的 ID 不清除。新增回归测试专门覆盖“不在捕获内的隐藏正文”、来源默认值与行内标记退休、粗体保留、定义/载体不替换，以及审阅内容不因来源回执而变化。

证据目录：`docs/assets/hcd-inline-deletion-2026-10-27/`。

15 项新增测试覆盖：完整包装器/嵌套包装器/内部提及、不同尺寸相邻节点与中间分隔文字、原位置失效、整块与外层覆盖、过期确认、再次迟到编辑及新 Y.Doc、个人撤销/重做、创建逆向回执、同伴仅改属性、伪造回执、旧协议拒绝、捕获之外的来源退休，以及恢复不能复制已移动子节点。完整 **966 项前端测试通过**，最终 TypeScript 与 standalone/embed 双构建通过。

实际鉴权 HTTP 流程使用无源 r8 HCDZ 的新副本，输入归档保持不变：

1. Alice 删除首个容器，r9 规范内容不再包含其正文；两条原有提及关联由 Alice 删除。
2. 服务成功提交 r9 后，代理断开真实 TCP 响应。同时另一份离线 Y.Doc 对被隐藏正文输入“迟到删除正文😀”并修改属性。服务端持久化这些状态，保存门禁显示删除审阅。
3. 原 Node 进程结束，另一进程从实际服务端 Yjs 字节和签名捕获恢复未知提交为 r9；隐藏正文、属性和删除回执仍可审阅。
4. 两个并发的恢复请求经协调器队列只插入一次；r10 实际保存成功，完整递归来源与规范响应一致。两条恢复的提及由实际恢复者 Bob 创建，不冒用原删除者；提醒关闭。
5. 原 r9 请求精确重放仍返回 r9，head 保持 r10；缺模型头为 426，只读写入为 403。
6. r9/r10 各导出 DOCX、PPTX、PDF、Markdown，共八份文件。回读验证删除版本不含隐藏正文，恢复版本包含迟到正文、对应属性呈现、嵌套文字和准确提及数量。HCDZ 离线重开 r8/r9/r10 投影一致；原始资源字节和 SHA256 一致。

## 边界与后续

这是内部结构 store、绑定、协调器和原生文件的验收；没有声明公开 SDK、公共属性/审阅视图、活动 Hocuspocus 房间、生产权限服务或 Office 桌面实测完成。公共 SDK 的行内容器定义与只读/缺 codec 视图、房间协商/迁移、复制/显式迁移、跨设备恢复，以及原七阶段其余要求继续推进。

若被删除外层中的某个子节点已经移动到其他可见位置，恢复整个旧外层会造成重复身份，因此当前原子拒绝该操作并保留审阅。还需要面向用户的此类结构冲突处理。

HCDZ 本次验证的是规范版本历史、资源和恢复后的内容；检查发现该归档没有 Yjs 协作状态条目。未保存的迟到输入/审阅依赖另存的持久 Yjs 状态，不能声称仅下载规范 HCDZ 就包含全部待处理协作历史。导出内容回读也不等同于所有布局、样式或再导入保真。
