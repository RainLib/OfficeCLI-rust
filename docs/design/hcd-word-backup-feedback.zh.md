# 区域 Word 设备备份下载反馈与生命周期

2026-10-30。整体目标中的保存/恢复一致性增量。管理平台与提醒保持后置，分页、页码重算、目录和其他格式不因本批完成而关闭。

## 问题与结果

区域 Word 的普通编辑页会捕获下载错误，但没有下载期间的重复操作保护和统一的可读说明；恢复比较页和部分错误页直接丢弃下载 Promise，异常可能没有对应的产品反馈。断开会话页另有一套处理。四处按钮现在共用 `WordDeviceDownloadButton` 和 `WordDeviceDownload`，沿用原有设备备份编码及下载函数。

一次准备只保留一个 Promise；按钮显示准备中并禁用重复操作，失败后可以重试。错误只显示已知类别，不回显原始错误、端点或令牌。浏览器接到下载请求后提示用户核对文件，不显示“下载成功”或“文件已保存”。提示可以关闭；准备中不能通过关闭提示绕过任务。普通编辑页中的提示浮在按钮上方，不改变 30px 状态栏高度；恢复和错误页面内自然换行。

| 错误码 | 含义 | 行为 |
| --- | --- | --- |
| HCD-BACKUP-1001 | 无法准备备份，含未归类的设备读取/文件交付异常 | 保留草稿、显示安全说明，可重试 |
| HCD-BACKUP-1002 | 文档身份或读取期间的设备副本发生变化 | 不交付旧文件，返回当前副本后重试 |
| HCD-BACKUP-1003 | 备份超过现有大小上限 | 不降低上限、不截断文件，保留设备草稿并明确此次未生成下载 |

## 生命周期与保存边界

控制器按设备 cache 和已认证 Session 绑定。切换渲染时立即通过当前绑定引用拒绝旧结果，不只等待 effect 清理；卸载后也不交付文件或更新新实例状态。React effect 创建并清理实例，避免 StrictMode 重放后复用已销毁实例。订阅在销毁时清空；同步订阅回调也不能重入创建第二次准备。

组件不向服务器提交、不消费本机更新、不合并恢复内容。仍沿用备份前的本机 `flush`、规范读取、摘要及大小校验。生命周期失效阻止最终文件交付，不等于中止已经开始的底层读取/编码。旧协议的设备备份列表及独立兼容性恢复页已有自己的 busy/身份检查，本批没有把这些入口全部迁入新组件。

中英文和繁体三套文案覆盖当前五个 locale。新组件已复查 effect 依赖、实例清理、`useSyncExternalStore` 快照、`aria-busy`、禁用态、状态/错误播报及可键盘访问的关闭按钮，依照本会话已使用的 React 检查清单，不引入新的组件库。
