# 区域 Word 的首版屏幕分页

2026-10-30。当前节的简单流式正文已经接入普通区域 Word 页面。它使长段落在等尺寸纸张间继续排版，仍然使用同一个区域编辑器和永久协作模型。**这不是精确 Word 排版、跨节连续文档、计算域或自动目录的完成声明。** 全部格式目标继续，管理平台和实际提醒后置。

## 实现

- `wordPageFlow.ts` 在显示层插入不可编辑的 CSS shape-outside 排除区；不创建页面正文节点、不拆分段落、不写 Yjs、不改变作者。页数按正文可用末端计算，避免内容已超出正文区、尚未超过纸张底边时漏增一页。
- 布局事务不进入个人历史。内容、宽度、缩放、字体和图片变化触发有界重新测量；组合输入期间暂缓。最多 512 页和 12 轮；无法处理的对象、无效几何或不支持的浏览器保留完整连续正文，明确显示连续排版。
- `WordPageSurface.tsx` 负责纸张背景、页间隙和页眉页脚位置。每个逻辑区域只有一个活编辑器；重复位置复制已经处理过的节点视图，副本不可编辑，隐藏源也不接受焦点。双击纸张页眉/页脚后，唯一的活编辑器在对应纸张原位编辑。
- 首页、默认及偶数页分别解析原绑定，缺少变体保持空白。正文预留当前节可能使用的最大页眉/页脚高度。后续节在前节页数未知时不猜奇偶性：奇偶绑定不同时，保留所选变体的连续预览并提示原因；绑定相同时可以继续分页。这也是跨节整本排版仍未交付的一部分。
- 重新测量期间保留上一份完整纸张布局，避免纸张暂时缩成一页造成焦点和滚动跳动；激活边框不参与高度。屏幕页数不写入域缓存，不改变 DOCX 的纸张、分节或编号设置。

## 本批实际发现并修复

1. 原模块属性的空对象分支被 TypeScript 推导为含 `undefined` 的索引值，阻断当前检查；补明确字符串映射返回类型。
2. 已排版文档的页数估算只按纸张末端判断，末页正文溢出可能没有新增页；改按可用正文末端并补边界回归。
3. 页眉激活导致重新测量时页面暂时收缩、原位焦点移动；保留上一份纸张布局，并移除编辑边框的高度影响。实际第三页重新激活后，仍为 ready/4 页，活页眉和第三页页眉位置相差约 0.56 CSS 像素（纸张边框）。

## 验证证据

普通 Chrome 区域入口、实际本机 sidecar/native 服务及合成 DOCX：

- Alice 通过普通正文输入将一个段落排为 4 页，纸张宽高一致。DOM Range 逐行几何与所有排除区比较，无文字与页间隙相交；保存成功为 r2。
- 个人撤销缩回 1 页，重做回到 4 页；缩放 25% 后重新收敛为 4 页。Bob 打开后看到相同 6184 字符正文和 4 页，并输入自己的后缀。Bob 对最后一组中文输入的撤销/重做保留长正文，不宣称一次撤销删除了他全部输入。
- Alice 在同伴输入后的撤销按钮操作发生浏览器焦点/CDP 超时，执行结果未确认，**不算通过**。后续没有凭超时重复点击撤销。
- 修正布局收缩问题后，在第三页双击并原位编辑共享页眉，普通保存为 r4，图片和正文保留。此前 r3 与最终 r4 的实际 DOCX 均回读正确。
- 实际 HCDZ 解包，r4 的 58 个规范文件逐字节相同，r0–r4 投影逐版本相同；正文仍是一个段落，布局和绑定未变化，显示分页标记未进入规范内容或 DOCX。没有把 CLI 导出说成浏览器文件下载。实际 DOCX 再导入，以及解包 HCDZ 不传 `--source` 导出语义 DOCX，均保留正文、同伴后缀、页眉和两节结构，见 [往返回读](../assets/hcd-word-page-flow-2026-10-30/roundtrip.json)。
- 独立 Tiptap 浏览器夹具插入代码块时清除分页排除区、保留原段落及完整代码；撤销后恢复 4 页，增加十段后正确增长到 5 页。这一项是引擎夹具，不是主页面复杂块验收。
- 实际区域模型回归检查显示分页元数据不改变 Yjs 编码字节、检查点和个人历史；普通文字撤销/重做保留远端页眉。
