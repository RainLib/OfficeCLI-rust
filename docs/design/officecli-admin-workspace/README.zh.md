# OfficeCLI 后台管理 · Soft Canvas / V2

使用本机 [pen.dev](https://pen.dev) 的设计技能与 MCP，在 [officecli-workspace-v2.pen](../officecli-workspace-v2.pen) 中新增后台章节，画板编号 **49–65**。设计复用 V2 的颜色变量、主要按钮，并新增共享后台导航组件。

[交互式审阅入口](./index.html) · [页面总览](./overview.png) · [17 页 PDF](./officecli-admin-workspace.pdf) · [画板清单](./manifest.json)

管理台现已按此设计接入 React 页面与 Rust 服务。运行说明见 [管理台 README](../../../examples/hdoc/admin-app/README.md)，真实流程截图与验证结果见 [验收目录](../../acceptance/hcd-admin-workspace/validation.json)。静态设计稿中的身份、数量和日期仍为示例数据；运行页面显示实际服务数据。

## 视觉一致性

沿用现有 [V2 规范](../officecli-workspace-v2/README.zh.md)：应用背景 `#ECEFF4`、内容区 `#FFFFFF`、正文 `#272D3B`、次要文字 `#667287`、主色 `#5865C7`、浅选中态 `#EDF0FC`、主操作 `#292F40`。深色页面直接使用原设计的 `mode: dark` 变量，不另建一套配色。

桌面画板 1600 × 1040，手机画板 390 × 844。外边距 16px、主区域间距 14px、导航与内容舱圆角 28px、详情区域圆角 18–20px、控件圆角 10–13px。字体沿用 Noto Sans SC / Inter；品牌字面预览按内容切换。

后台侧栏分为工作空间、品牌资源、服务管理三组；主要内容使用单一白色内容舱，详情按需在右侧显示。桌面保留返回文档工作台入口，手机使用卡片列表和底部导航。

## 与当前文档编辑后台的对应

设计范围参考了现有后台的 [导航](../../../examples/hdoc/admin-app/src/components/AppShell.tsx)、[文档管理](../../../examples/hdoc/admin-app/src/views/DocumentsView.tsx)、字体/主题/预览/上传/操作记录页面，以及 [文档服务路由](../../../crates/officecli/src/hdoc_server.rs)。范围为当前本机服务，没有加入组织成员、付费套餐或多租户管理。

| 能力 | 当前依据与实现接入说明 |
| --- | --- |
| 字体、修订、授权登记与主题管理 | 现有管理台与 catalog 接口已覆盖主体能力；设计调整布局并强化字面、授权和引用信息 |
| 文档目录、指定主题、批量指定与字体计划 | 现有文档页已有对应功能；新的筛选维度、文档名称与状态需要补齐数据映射 |
| 历史修订、恢复、格式感知导出 | 文档服务和编辑器已有能力；后台详情、预览与恢复入口需要接入文档令牌 |
| 导入任务 | 已有导入与 job 状态接口；后台全局列表与历史汇总需要额外持久化或聚合 |
| 导出任务中心 | 当前导出与下载接口可复用；页面中的统一任务历史和百分比需要新增任务数据支持，不表示已有统一导出任务接口 |
| AI 任务 | 当前 agent-runs/agents 按文档提供数据；后台跨文档列表、计数与待办需要聚合，不把进程内记录当作长期历史 |
| 访问令牌 | 当前通过 CLI 签发；页面生成签发命令，不在浏览器保存签名密钥。未设计虚构的全局令牌清单或单令牌撤销接口 |
| 操作记录 | 当前接口为 catalog 操作记录；正文、Agent 与恢复记录留在文档修订中。新增筛选应声明筛选窗口与截断情况 |
| 服务设置 | 健康检查可复用；协作/MCP 的完整状态、目录元信息需增加只读接口。目录修改依然通过启动配置完成 |

## 关键交互约定

- **文档入口**：从后台打开文档时恢复其独立标签状态；预览与编辑按文档能力和权限显示，Office 页、表格网格、幻灯片保持各自形态。
- **恢复修订**：先预览所选版本，确认时重新检查最新修订；恢复创建新修订并保留中间历史。版本变化时保留当前选择，要求重新查看最新内容。
- **后台与文档权限**：admin 管理字体、主题并可指定文档主题；恢复版本与修改内容使用该文档的 write 权限。缺少权限时保留查看能力并给出具体入口。
- **批量指定主题**：只处理当前筛选范围、未指定主题且已导入完成的文档；管理员可执行主题指定；退役主题不可作为新目标。逐份校验修订和反馈结果，失败不覆盖已完成项目。
- **字体授权**：分别展示网页预览、OOXML 嵌入、PDF 嵌入、再分发四项；日期到期与即将到期区分。修订不可变，更新授权登记为新的修订。删除前检查主题及历史引用，被引用时阻止删除并列出引用来源。
- **主题退役**：停止新增指定，历史固定关系仍保留。新主题修订不自动修改已经固定主题的文档。
- **导出检查**：字体计划绑定文档修订与输出格式；说明“嵌入”或“仅保留名称”及原因。XLSX 不承诺嵌入字体；PDF 文本替换预测按服务返回结果呈现。
- **AI 任务**：显示目标文档/范围、有效步骤与真实提交修订。收到冲突先重新读取；停止后说明已有提交仍保留。远程定位不抢走人工焦点。
- **会话**：令牌仅保存在 sessionStorage，界面隐藏完整令牌；会话过期保留筛选与草稿。签发命令遵守现有 CLI 的 scope、document-id、user-id 和 1–3600 秒有效期约束。
- **反馈与可访问性**：状态同时用文字与颜色；表格行名称可点击，图标有名称；弹窗支持焦点圈定、Esc 关闭和焦点返回。错误保留输入，重试不重复已完成写入。手机端将详情改为抽屉，避免压缩桌面表格。
- **动效**：沿用 V2 的 200ms ease 面板过渡，尊重减少动态效果偏好。静态稿不代表已实现动效。

## 审阅与验证

在仓库根目录执行：

```bash
open -a Pen docs/design/officecli-workspace-v2.pen
open docs/design/officecli-admin-workspace/index.html
open docs/design/officecli-admin-workspace/officecli-admin-workspace.pdf
python3 docs/design/officecli-admin-workspace/validate.py
```

在 Pen 中查看 49–65 号画板；`manifest.json` 保存画板 ID 与 PNG 的对应关系。离线审阅页支持总览/单页切换、选择页面和左右箭头切换。

交付检查：统一 V2 颜色与主按钮、桌面/手机/深色、表格与长文字、授权与文档权限、失败与冲突反馈、修订恢复、批量跳过与结果提示。逐页导出 PNG 并检查视觉；自动检查画板尺寸、节点 ID、变量引用、未完成标记、画板重叠及交付文件完整性。验证结果见 `design-validation.json`。离线审阅页通过浏览器验证：17 张图片完整加载、总览/单页切换、下一页、页面选择及 390px 宽度无横向溢出。

实现已通过前端构建、目录与后台 Rust 测试，以及桌面 / 390px 手机端的真实浏览器验收。导入导出显示实际状态；AI 列表仅代表当前服务进程记录。Pen 中新增桌面与手机运行画布，可与静态设计直接对照。
