# HCD 编辑器上下文属性侧栏分析

日期：2026-10-23。本文记录现状核对和待实施设计，不表示新增控件已经可用。范围包含 PPT、Word、PDF；云文档管理平台、字体上传管理平台继续后置。

## 设计结论

右侧以当前选择为入口，将属性分为页面、文字、段落、对象。点击页面空白、选择文字框、选中框内文字、选择图片，应有不同的属性内容与作用范围。顶部操作区提供高频命令，右侧提供同一选择的详细属性，两处共享状态、撤销和保存结果。

参考的交互逻辑：

- Photoshop 的字符格式可以作用于选中字符或整个文字图层；属性面板是其格式入口之一。参考 [Adobe 字符格式说明](https://helpx.adobe.com/photoshop/desktop/text-typography/characters-glyphs/format-characters.html)。
- Office 根据所选图片、形状、文字框等显示对应的上下文选项卡。参考 [Microsoft 菜单和工具栏说明](https://support.microsoft.com/en-US/PowerPoint/where-are-the-menus-and-toolbars)。

HCD 据此采用下面的选择和分组方案。具体字段、尺寸和实施顺序是本项目的设计建议。

| 紧凑布局 | 面板收起、拖动宽度、键盘调宽；固定版式属性宽 220–440px | 分组密度和状态展示需统一；记忆面板布局、窄窗口行为仍需明确验收 |
| 样式保留 | 普通文字替换可保留原 HTML 结构；Word 字号与文字联合修改已通过来源 mark 保留原稿样式、保存重开及原生导出 | 部分格式变化会触发整块重建；仍需保留原段落/字符样式、未编辑属性和来源关联 |

## 选择决定属性与作用范围

| 当前选择 | 面板标题与分组 | 修改作用范围 |
| --- | --- | --- |
| 页面空白 | 页面：尺寸/方向、版面、背景 | 当前页或明确指定的节/页面范围 |
| 文字框边框 | 文字框：位置与尺寸、框内排版、文字、段落、外观 | 当前文字框；字符格式明确标示“整个文字框” |
| 框内一段文字 | 文字：字符、段落；折叠显示所属框属性 | 字符操作只作用于选区；段落操作作用于选区涉及的段落 |
| Word 正文光标 | 文字：字符、段落、当前样式 | 字符作用于后续输入，段落作用于当前段；已有文字范围需另行选中 |
| 图片 | 图片：位置与尺寸、替换/裁剪、排列；Word 另有环绕 | 当前图片实例；共享同一资源的其他图片不被连带修改 |
| 多选对象或混合文字 | 所选 N 项/混合；只显示共同属性 | 仅改用户明确调整的字段；其余各自保留 |
| 扫描 PDF 页面 | 页面；可识别内容能力说明 | 没有可编辑文本对象时，不提供虚假的文字修改入口；OCR 为独立待实现能力 |

交互细节：

1. PPT 单击文字框边界选择对象，双击或明确进入文字编辑后选择框内文字；PDF 先按其真实可编辑文本对象定位，不能假定它存在 PPT 式段落和文本框。
2. 点击侧栏输入框后保留画布选区；输入法组合期间不重建文字。切换对象、页面或折叠面板不丢草稿。
3. 点击空白取消对象选择；Esc 分层退出文字编辑与对象选择。翻页清除已不存在的选择，不暗中选中第一页文字。
4. “混合”“继承”“缺失字体”“只读”分别展示。混合颜色不显示成默认黑色；继承字体不被浏览器回退字体覆盖。
5. 对象列表作为折叠的定位工具；属性区默认聚焦一个对象，避免堆叠整页内容编辑框。
6. 页面模式必须有明确入口。Word 光标通常始终存在，可通过“布局 → 页面设置”进入当前节属性，不能仅依赖点击正文周围空白。

## 侧栏内部结构

固定顶部显示“属性 · 当前对象”，以及页面/节和对象名称。下方采用可折叠分组，常用字段优先；详细设置按需展开。

| 分组 | 内容 | 格式差异 |
| --- | --- | --- |
| 页面/版面 | 尺寸、方向、页边距、背景；应用范围 | Word 以节为核心；PPT 尺寸通常影响整份演示文稿；PDF 页面框、旋转和内容缩放须分开处理 |
| 字符 | 字体、字号、粗斜体、下划线、颜色、高亮；详细字距、基线、语言字体槽 | 依据实际字体与导出能力开放；PDF 嵌入字体可能只有子集 |
| 段落 | 对齐、缩进、行距、段前段后、列表、文字方向 | Word/PPT 使用各自段落语义；PDF 只有可靠恢复段落时才提供 |
| 文字框排版 | X/Y、W/H、旋转、内边距、垂直对齐、自动换行及溢出策略 | PPT 核心能力；Word 区分正文段落与浮动框；PDF 几何为真实文字区域 |
| 图片 | X/Y、W/H、锁定比例、替换、裁剪、旋转、透明度 | Word 环绕与锚定、PPT 对象排列、PDF 内容流变换分别实现 |
| 外观与排列 | 填充、边框、阴影、对齐、前后顺序 | 按对象支持范围显示，不将原稿没有的属性推断成已实现 |

“缩略图显示、属性栏宽度、缩放、紧凑密度、重置工作区”移至视图/工作区设置。它们不写入文档内容 revision，也不与页面背景、纸张尺寸放在同一组。

## 紧凑布局与操作区

- 保留现有可调宽度；默认属性栏约 280px。标准桌面控件高度建议 28–30px，同类按钮组成一行，X/Y 和 W/H 两列排列；触控模式增加点击面积。
- 分组标题与输入标签保持清楚，详细说明按需展开；字体列表、对象列表等采用有界按需加载。
- 小窗口将侧栏收起为可打开的面板，避免持续压缩画布；可用键盘聚焦和关闭，关闭后焦点返回原入口。
- 保存、导出继续放在上方操作区，使用当前保存协议。属性栏显示草稿/冲突反馈，不再增加一套含义不同的“保存全文”入口。
- 统一常用分组、单位展示和交互；各格式保留自己的版式语义。用户界面切换语言不改正文语言、单位底层数值或文档方向。

## 保存、协同和能力条件

新增属性以“能保存、能重开、能导出”为开放条件，不能仅在预览 CSS 生效。字段需要区分可编辑、原值只读、混合、不适用；暂不可编辑但有原值的字段保留展示并说明原因。

属性变更需包含对象/字符范围、基础 revision 和格式前置条件；仅检查文字 hash 无法发现另一个人只改字号的冲突。保存期间的新输入继续保留。字体、段落或框尺寸变化不应触发无必要的整段重建，不能覆盖未编辑样式。

远端在线选区与本地正在编辑的属性分开显示。远端更改当前对象时，保留本地草稿并提示冲突；只读用户仍可检查属性。完整 Word 的文字与图片位置/尺寸已统一协调保存，迟到同字段草稿保留冲突选择。图片替换同批事务、图片属性撤销重做及正文选择性冲突合并仍需补齐，不能用在线人数代替协同保存验收。

属性栏仅请求当前选择和必要元数据。长文分段模式继续按分片加载；进入完整 Word 模式仍会加载全文，不能把按需加载字体或对象列表称为完整 Word 正文分页。

字体身份、语言字体槽、回退和原稿保真约束沿用 [字体与国际化设计](hcd-fonts-i18n.zh.md)。

## 实施顺序和验收

1. **先保内容与样式**：优先解决格式修改重建原块的问题，验证未编辑样式、来源关联和历史保留；继续完善保存事务。页面和属性 redesign 不绕过这一条件。
2. **统一选择与侧栏结构**：建立页面、对象、字符范围、混合选区状态；分离文档属性与工作区设置；正确回显原值和混合值。
3. **按能力补属性**：Word 字符/段落与当前节，PPT 文字框/字符/段落，PDF 可靠对象和页面几何；每个字段分别贯通保存、重开、原生或语义导出。
4. **补齐跨端体验**：国际化、字体可用性、协同格式冲突、撤销重做、长文按需加载及窄屏布局。
5. 编辑能力稳定后，再开展 WPS 云服务式的文档、成员权限、字体目录和运维管理平台。

验收场景：

- 单击框边界与选中部分字符后，属性和作用范围正确；改变部分中文/英文/emoji 的字号，邻近内容和原样式不变。
- 混合字号/颜色显示混合状态，改变一个字段不重置其他字段；焦点进入侧栏后保留原文字选区。
- 页面/节尺寸和方向明确告知应用范围；视图缩放或重置面板不生成内容修改。
- PDF 点击真实位置的文字、图片可定位；旋转/裁剪页面也准确；扫描页没有虚假文字编辑器。
- 文字和图片草稿跨页、折叠、异步保存不丢失；远端同对象格式变化可处理冲突；只读权限不可提交。
- 保存重开与导出分别验证当前内容、格式和位置；旧 revision 不变；不能把语义重建等同于源文件完全保真。
- 长文打开属性不请求全文；简体/繁体/英文及窄窗口不遮挡关键字段，键盘可操作面板与输入控件。
