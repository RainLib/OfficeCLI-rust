# PPTX 原稿图片几何导出：当前进度

已将满足源校验条件的图片位置、尺寸和图片替换接入 PPTX 原稿导出及服务端预检。替换支持 PNG、JPEG、GIF，单张资源最多 64 MiB，尺寸不超过 16384 像素和 6400 万像素；不支持的源结构或图片格式会拒绝。无源生成的 PPTX 是独立能力，不能代表原稿往返兼容。

`hcd-formats` 新增了独立的源幻灯片 XML 图片几何重写基础：按图片形状 ID 寻找未分组图片，只替换其位置及尺寸；缺失或重复身份、缺失或重复几何、分组图片、非支持的命名空间和不完整 XML 会拒绝。输入大小、事件数和嵌套层数有限制。测试包含从实际 PPTX 抽取的幻灯片 XML，并检查其他 XML 内容保持不变。

另有带源校验的重写入口，检查形状 ID 在幻灯片中的唯一性、导入时记录的原始几何、图片引用的关系 ID 和关系命名空间。独立的包级校验入口解析内部图片关系，核对关系目标及源包媒体字节的哈希，并拒绝重复关系 ID 和外链。这两个入口都不检查源文件哈希和版本。

按保存版本生成候选幻灯片 XML 时，会比对源文件哈希、版本 0 与目标版本的图片映射和资源，检查源关系及原始几何，再应用修改；同一幻灯片的文字修改会在候选 XML 上继续应用。替换会添加独立媒体、内容类型和关系，仅更新目标图片，保留共享原媒体。自动化测试覆盖跨两页文字和几何混合导出、旧版本、共享原图的替换及新媒体字节。分组图片和无法核验的源结构仍会被拒绝。

真实文件验证：仓库 `examples/ppt/pictures/pictures-basic.pptx` 能被 LibreOffice 转换，改变一张图片宽度并导出后也可转换为 PDF；转换前后均为 5 页，页面尺寸相同，包内只有对应幻灯片 XML 发生变化。此样本使用局部 XML 命名空间声明，校验已支持正确的局部声明，并继续拒绝错误绑定。最初使用的另一个自造样本原稿和导出文件均不能被 LibreOffice 加载，不能作为外部兼容证明。

本地 HTTP 回归使用真实 PPTX 和新版独立服务，验证几何修改后的 r1 预检和源导出、r2 替换后的预检和源导出、新媒体字节与原有媒体保留，同时验证历史 r1 仍可通过预检。脚本为 `scripts/hcd-pptx-source-geometry-http.py`。

隔离浏览器测试从已保存的 r1 打开同一真实 PPTX，将第一张图片宽度改为 270 pt 并保存为 r2；“保留原文件”导出显示成功。使用同一 r2 和源文件通过 CLI 独立导出，读取对应图片宽度为 3429000 EMU（270 pt）；浏览器实际下载文件本身未独立读回。界面截图见 `docs/assets/hcd-pptx-source-geometry-2026-10-28/browser-export-r2.png`。

还需要对多图片、多页、旋转与裁剪、并发保存、离线恢复和预检与实际导出一致性进行更广泛验证；LibreOffice 转换证明文件可打开，但不等于逐像素显示或 PowerPoint/WPS 往返验收。

图片替换还通过隔离浏览器验收：选择本地 PNG，保存到 r2 并以“保留原文件”下载 PPTX；直接读取浏览器下载文件确认新增媒体字节相同，LibreOffice 可将该下载文件转换为 PDF。截图见 `docs/assets/hcd-pptx-source-geometry-2026-10-28/browser-replace-export-r2.png`。该验证不代表 PowerPoint/WPS 或协同、断网恢复的完整验收。

版本接入时发现格式导出原先自行重建历史 manifest，却沿用了当前版本的索引页数和分块数。现已改用 HCD 核心的历史 manifest 解析，使历史版本使用自身记录的页数和分块数。自动化测试构造了 129 个分块、修改第二索引页中的文本，再进行真实结构编辑将当前版本合并为一个分块；随后导出旧 TXT 并验证全部内容和修改。该测试覆盖共享版本逻辑与 TXT 文件导出，不代表其他格式的全部历史导出场景已验收。
