# 常用办公能力与设计对应

本表区分当前源码可见的能力与本轮设计目标。源码核对用于避免删去已有操作，不等同于本轮重跑了产品验收。

| 能力 | 当前核对依据 | V2 设计 |
| --- | --- | --- |
| 文字基础编辑 | App.tsx 的正文/标题、粗斜体、链接、列表、段落移动等入口 | 常用工具栏与文档页，11 |
| 文字更多常用操作 | 本轮没有逐项证明字体、页眉页脚、完整审阅修订均能运行 | 字体字号、样式、布局与审阅目标，11–12 |
| 文字查找替换 | 本轮不将新设计视作运行验证 | 查找、结果定位、替换字段与入口，29 |
| 表格基础编辑 | UniverViewer.tsx 的字体、填充、对齐、边框、数字格式、合并、工作表、冻结和行列操作 | 常用编辑与公式，13 |
| 表格数据处理 | 本轮没有逐项验证图表或筛选的持久化 | 筛选与图表，14；查找替换，30 |
| 图片基础编辑 | ImageWorkspace.tsx 的裁剪、旋转、翻转、尺寸、光色及应用版本 | 15–17 |
| 图片局部 AI | 当前源码已有蒙版、任务、候选、应用前版本检查等独立图片流程 | 涂抹、生成中、对比接入全局 AI 的设计，18–20 |
| 图片格式转换 | 当前源码按格式处理质量、透明、背景填充及副本 | WebP/JPEG/PNG 对应参数和结果，21–23、31 |
| 图片历史与视图 | 当前源码已有历史选择、缩放和平移等状态 | 24–26；手机版是布局样例 |
| PPT/PDF | 当前已有独立格式编辑/展示代码；本轮没有做这两种格式的完整运行回归 | 常用演示与阅读批注，27–28 |
| 白板资源引用 | 沿用上一轮资源身份、范围、版本与视图约定，仍待产品接入 | 01–08，完整编辑入口连接 11/13 |
| 全局 AI | 现有各格式能力不自动等于跨资源会话已经迁移完成 | 持续对话、固定资料、当前资源和任务统一表达 |

主要核对文件：

- examples/hdoc/editor/src/App.tsx
- examples/hdoc/editor/src/UniverViewer.tsx
- examples/hdoc/editor/src/ImageWorkspace.tsx
- examples/hdoc/editor/src/EditorChrome.tsx
- docs/design/officecli-workspace/README.zh.md
- docs/design/officecli-image-workspace/README.zh.md
- docs/design/officecli-resource-workspace-v1/README.zh.md

实际开发时应继续沿用已有文档与图片引擎，补齐工具展示、资源视图和全局状态连接；各工具是否可执行以能力信息与权限为准。
