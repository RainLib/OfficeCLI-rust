# 区域 Word 原窗口的普通断线重连（2026-10-30）

修复布局感知 `/2` 的[分节编号验证](hcd-word-numbering-settings.zh.md)发现的实际问题：页面事务已成功交接后，侧车再次重启，旧窗口点击“重试”仍无法恢复，只有关闭重开才能继续。旧 `/1` 不由本批自动迁移；完整 HCD 目标继续，管理平台和提醒后置。

## 原因与修改

`WordLiveSession` 成功交接后一直保留旧 `round`，普通断线也未将其失效。编辑页按 `requestId` 选择重试方式，因此把普通断线误当作旧结构操作尚未完成；重启后的服务已不再提供该活动轮次，原窗口反复查询旧编号。

现在明确区分两种情况：

1. 仍未确认的页面/story/link 交接保留原编号，继续原操作核对，不改成普通重连。
2. 普通连接断开时，原视图冻结并保留。用户点击“重试”后，新传输从空 `Y.Doc` 加入，读取并核验原生投影，版本不得倒退；通过既有拓扑和完整状态包含性检查后，将新房间状态接入原视图。成功交接清除已完成编号和普通重连标记。

`RegionalWordEditor` 使用显式 `canRetry` 选择原会话重连，保留同一视图、个人撤销管理器和设备日志。检查失败进入恢复提示，可下载备份、重试或打开恢复工具，不把旧快照直接作为新房间的初始数据，也不静默删除本机输入。

普通断线仅显式重试，不因后台连接恢复而自动复活旧传输。鉴权失败不能使用普通重连恢复写权限；只读会话接续后仍只读。新房间未包含本机旧视图、拓扑不符、版本倒退、校验失败及过大状态仍拒绝直接接续。现有状态包含性检查有 8 MiB 限制；跨基线私有草稿合并、历史压缩和跨主机接管未由本修复完成。

## 专项验证

先增加 7 项回归，在修复前的 16 项会话测试中 7 项失败，日志保留为 `regression-before.log`。修改后的 57 项会话、浏览器状态和桥接专项通过，覆盖：

- 页面、创建 story、链接前节成功后再普通断线，重试不查询已完成编号。
- 尚无结构操作时的显式重连，所有新传输均为空文档起步。
- 原文档 client ID、个人撤销/重做和设备日志保留，同伴文字不被自己的撤销移除。
- 本机未确认输入不作为服务端初始数据；比较拒绝后原字节仍在设备日志，原服务正文不变。
- 只读和鉴权失败保护，既有未知结构轮次、迟到输入、销毁和异步取消检查继续通过。

这些使用 fake-indexeddb 和受控 Provider，不替代下述真实浏览器与文件证据。限制并发的完整前端 **2036 项全部通过**，含 TypeScript 的独立版/嵌入版构建通过。最终记录以 [validation.json](../assets/hcd-word-reconnect-2026-10-30/validation.json) 为准；默认高并发运行的侧车启动不稳定是上批记录的独立开放项，本批不扩大其通过范围。

## 原窗口、真实服务和实际文件

使用新建的隔离合成 DOCX、真实原生进程/侧车和三个普通嵌入页。Alice、Bob 为写成员，Reader 只读。页面 ID 始终为 28、29、30；重启期间没有刷新、关闭或重新打开这些页面。

| 版本 | 实际操作 |
| --- | --- |
| r1 | 导入并分区，保留两节、原纸张、页眉页脚和图片 |
| r2 | Alice 追加并保存自己的文字，建立个人历史 |
| r3 | 普通页面设置将第一节设为从 9 开始、大写罗马数字；原窗口完成自动交接 |
| r4 | Bob 又输入但未点保存；受控正常侧车重启的 drain 将该协作草稿保存，作者仍为 Bob |
| r4 接续 | 三个原窗口分别点击“重试”恢复；Reader 正文仍不可编辑，页面设置禁用 |
| r5 | Alice 在原窗口撤销自己的输入并保存，Bob 草稿保留并同步至另一成员 |
| r6 | Alice 在原窗口重做并保存，双方文字恢复各一次 |
| r7 | Bob 在原窗口继续追加文字并保存 |

重试前后代理中的页面请求记录完全相同，共 160 条；其中只有一次成功页面提交 r3，没有因普通重连重新查询或提交旧轮次。该数量是此命名样本的真实观察，不是所有文档的固定上限。

实际浏览器下载最终 DOCX、完整 HCDZ，以及重启前和重连后的两份 `/6` 设备备份。独立回读验证作者、正文、编号及图片；另从原生固定版本导出 r5/r6，确认撤销/重做内容差异，三个 DOCX 再导入均通过。实际 HCDZ 解包后完整回读 r1–r7，70 个规范文件与本机规范包逐字节一致；两份设备备份通过生产 reader 解码，包含各自应有的正文与相同最终布局。

证据：[原窗口观察](../assets/hcd-word-reconnect-2026-10-30/browser.json)、[文件回读](../assets/hcd-word-reconnect-2026-10-30/files.json)、[自己的撤销保留同伴](../assets/hcd-word-reconnect-2026-10-30/own-undo-preserves-peer.png)、[原窗口续存](../assets/hcd-word-reconnect-2026-10-30/after-reconnect.png)。

这是本机合成样本的正常进程重启，不是进程被强杀、断电、任意网络故障、跨物理设备或生产验收。新房间不包含本机输入时的拒绝/保留，当前仅有专项测试；本批没有浏览器完整走完该分支的恢复合并。没有实现分页、动态页码、目录或其他格式完整创作能力。
