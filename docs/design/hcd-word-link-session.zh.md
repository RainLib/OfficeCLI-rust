## 固定记录证明

独立区域创建可用 nonce 派生的新 story 身份核对，链接只移除绑定，不产生这样的目标 ID。因此，链接不能沿用“前后拓扑看起来改变”作为接续证明。

- 精确查询同一编号的布局状态；仅明确缓存未命中时查询独立区域状态，再仅在其未命中时查询链接状态。pending 不继续猜测其他事务；所有状态均绑定文档、epoch、编号、schema 和模型声明，不重新提交。
- 链接 installed 后，并行读取固定 rN-1/rN 投影及原生 rN 记录；现有投影读取有 30 秒和 16 MiB 上限，记录读取最多 1 MiB。
- 核对记录中的编号、父版本、补丁基准、作者、结构/布局变化及请求摘要；推导的变化必须恰好移除一个指定绑定，原内容、区域目录、批注及其他布局字段不变。
- 浏览器与服务端共用 native-compatible 请求字节配方，分别用 WebCrypto 和 Node SHA-256 核对 Rust 原生记录摘要。凭证和原生 HMAC 密钥不交给浏览器。
- 校验成功后只返回不可改写的进程内 proof token，固定投影副本存于私有 WeakMap；普通 JSON 复制不能冒充证明。原视图及新传输还须各自匹配对应拓扑，随后经过既有完整 Yjs 包含关系核验。证明是浏览器接续条件，不是原生写入权限。

只有这些检查通过，才解除旧传输和旧 PM 视图，合并已认证的新状态，并把后来合法增量桥接到新传输。旧本机状态不会作为新房间种子发送。迟到私有输入、未知结果或不完整副本进入恢复状态；原窗口及设备副本仍保留，不靠清空历史或重新载入页面伪装接续。

## 实际普通窗口验证

在隔离原生/侧车和三个普通嵌入页中，由 Alice、Bob 和只读成员预先进入同一个 `/2` 房间。通过浏览器实际输入双方正文，提交前的规范 r1 尚不包含这两处草稿；API 发起第二节偶数页页眉“链接前一节”至 r2。

1. 三个原窗口自动返回正常编辑视图，双方草稿保留。通过 CUA 的只读 `Page.getFrameTree` 核对，三者 root frame 和 loader 均未变化，链接期间没有页面刷新；只读正文仍为 `contenteditable=false`。
2. 草稿随后保存为 r3。Bob 在原窗口同一段继续输入并保存 r4；Alice 的一次撤销只移除自己的输入，保留 Bob 链接前后的文字，保存 r5；重做恢复 Alice 输入并保存 r6。
3. 在原 Alice 窗口切至第二节偶数页，显示继承的 `Even header`；双击纸张页眉进入原位编辑，操作区明确标记“链接前一节/共享内容”。添加文字并保存 r7，原只读窗口对应页眉同步可见，仍只读。
4. 原 Alice 页实际下载设备备份。此后才显式刷新 Alice（不是链接阶段刷新），正常重新打开 r7，正文完整且版本不增加。下载的 `/6` 设备备份按真实成员和端点作用域独立读取，包含四处标记、继承绑定及保留的原独立区域。

![原窗口自动接续后，第二节继承页眉仍可原位编辑](../assets/hcd-word-link-session-2026-10-30/inherited-header-edited.png)

原生与实际文件分别核对：r2 仅改变目标绑定且没有提前发布正文草稿；r5/r6 的语义 DOCX 保留同伴两次输入且只撤销/重做自己的输入；r7 修改落在继承源区域，原独立区域不变；所有导出保留原图片字节。HCDZ 解包逐版本比较 r1–r7，规范和离线校验通过。实际文件与下载备份见[回读结果](../assets/hcd-word-link-session-2026-10-30/file-readback.json)。不据此承诺跨刷新个人历史；本批个人历史验收发生在原页面跨链接期间。
