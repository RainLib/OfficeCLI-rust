# Word 区域富文本、事务绑定与提交准备日志

2026-10-26。此文记录底层和原生验收；后续已有[受开关控制的本机区域房间](hcd-word-room.zh.md)及实际 Socket 验证，不表示浏览器区域富文本已经启用。当前纸张页仍使用既有映射文本/图片保存；管理平台和实际提醒继续暂缓。

## 区域模型与编辑事务

`WordRegionStore` 用一个 Y.Doc 和现有 `SemanticBlockStore` 保存永久块、文字载体和来源关系。正文节、页眉、页脚按原生 flowLayout2 的稳定 region ID 分区，包括未绑定到页面的 story。内部边界节点只存在于协作模型；不接受 HTML 导入，不作为原生文档块，也不进入 checkpoint、DOCX 或 HCDZ 的规范正文。

`view(regionId)` 给现有 ProseMirror binding 提供一个区域的投影。块菜单和文字事务复用现有命令/来源/相对位置逻辑；没有复制另一套撤销或全文重建算法。另一区域的并发更新不改变当前事务的边界。区域编辑拒绝其他区域的结构 key、规范块 ID、来源 ID，以及对内部边界和只读 opaque 内容的改写。移除最后一个可编辑段落会留下空段落，不能删除整个 story。

初始化是显式操作。旧 default fragment、未知非空共享字段和不支持的模型声明不会被静默迁移。非区域的只读脚注/尾注不进入此编辑模型，由原生 checkpoint 保留；其他无归属的可编辑块拒绝进入。该模型仍要求完整结构状态，不代表超长文档的数据分段/虚拟化已经完成。

捕获包含每个区域的 SnapshotBlock 和永久来源位置。回执只重绑捕获时的载体，不替换当前文字；保存期间的新输入仍保留。规范块 ID、文字来源 ID和派生分节结束 ID 的回写不算用户输入，因此不能使已提交内容出现虚假的“又有修改”。

## 提交准备日志

`WordCheckpointJournal` 是服务端内部的私有恢复原语，尚不是自动保存协调器或分布式房间租约。

- 记录 API 摘要、文档、epoch、lineage、不可变基线版本/rootHash/layoutHash/digest、完整 Yjs 状态、原 checkpoint 请求、来源捕获和由调用方确认的协作者代次。
- 请求内容必须与捕获一致；其 digest 来自捕获本身，不能在提交时读取后来输入。待确认请求的 checkpointId 和作者代次保持不变。
- 发布者必须从可信鉴权上下文提供作者，不能把共享 Y.Map 中的人员声明当授权事实。日志签名不赋予文档写权限；原生 API 仍检查当前权限、epoch、来源归属和基线版本。
- 每条记录先完整写入临时文件并 fsync，再用 hard link 原子创建 `previousHash.next`。同一父记录只有一个后继，不能覆盖另一写入者。文件 fsync/目录 fsync 完成后才能开始规范提交。
- 全部内容以 HMAC 认证并压缩；API/文档/epoch/lineage 不匹配、签名不符、损坏记录、符号链接、非法来源绑定或 Yjs/模型声明均拒绝。损坏的已链接记录不能退回前一条并谎报“最新备份正常”。
- 私有目录/文件采用 0700/0600。记录不包含 bearer token 或签名密钥。临时孤立文件不会被当作已发布记录。

边界：Yjs 状态最多 8 MiB，准备记录 payload 最多 32 MiB，压缩文件最多 16 MiB，链最多读取 4096 条。尚未做链压缩、历史 GC、远端存储适配或多实例房间租约，不能据此宣称规模/生产验收完成。

## 已执行的真实验证

`python3 scripts/hcd-word-region-store.py` 每次创建独立文档、端口和服务端进程，不写入已有用户预览。

1. 创建含两节、共享/不同/未绑定页眉页脚、页眉图片及页码缓存的 DOCX，导入并显式投影为区域模型。
2. 两份 Y.Doc 并发移动正文块、输入中文/emoji、修改页眉和空页脚；原永久文字载体不替换。通过现有 ProseMirror binding 和块命令转换标题。
3. 提交前持久化原请求；本地代理在原生联合提交 r2 成功后直接关闭 TCP 响应。保存期间输入的额外页眉文字另写入同一准备链。
4. 结束第一个 Node 进程，启动另一个 PID。新进程从磁盘验证签名和基线，按原请求 ID 重放，得到 r2 的原收据，再重绑来源；后续输入仍在。
5. 已确认的 Bob 代次被扣除，之后 Alice 的额外输入保存到 r3，不再把 Bob 计入这次编辑。旧请求随后仍返回 r2，当前 head 保持 r3。
6. 当前来源越区请求返回 400，只读写入返回 403，均不发布新版本。测试人员为预置受控身份；真实 Hocuspocus 逐包身份观察尚未接入。最终日志不存在未知待确认请求，重建的 Yjs 模型与规范内容一致。
7. 实际 DOCX 中正文/标题/页眉/页脚放置正确，原图片字节和只读页码缓存保留。HCDZ 离线重开 r1/r2/r3 完全一致，原生和离线 bundle validate 均通过。

证据：`docs/assets/hcd-word-region-store-2026-10-26/model-api-and-files.json`、实际 DOCX/HCDZ 及日志。13 个区域模型/事务测试、6 个准备日志测试纳入全部 783 个前端测试；生产与嵌入构建通过。以上是本机原生 HTTP、实际断流、独立进程和文件证据，不是浏览器房间或 Office 桌面验收。
