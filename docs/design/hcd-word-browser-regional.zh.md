## 已接通

- 正文、页眉、页脚使用同一个 Y.Doc 和房间，分别显示 scoped ProseMirror 视图。内部区域边界不进入正文、剪贴板或导出。每个视图使用自己的编辑器 schema，避免跨 schema NodeType 造成写入失败。
- 纸张在工作区居中，节导航默认收起，保存/导出位于操作区。底部显示节、真实纸型/方向和页眉页脚变体；所有节以共同宽度基准适配。不同节只有源文件确实指定不同纸型/方向时才显示不同尺寸。
- 双击页眉页脚或通过插入工具进入原位编辑，正文变淡；在正文双击退出。已有区域中的空段落可以输入，尚不能创建缺失的 story。
- 复用统一命令、工具栏、快捷键、右键、`/` 搜索菜单、块手柄/操作、选区浮层、链接和服务端人员 `@` 菜单。临时段落 ID 可通过房间守卫；原生来源 ID、跨区来源和只读内容仍受保护。
- 全局个人撤销/重做共用同一永久载体。正文撤销不会撤销同伴的页眉修改。未聚焦的区域不再清除另一区域正在发布的姓名光标。
- 右侧在线协作显示成员姓名、定位和跟随。区域与滚动进度同时携带所属节和变体，共用页眉不会再把第二节定位到第一节。手动滚动/输入停止跟随，跟随环路被拒绝。
- 现有页眉图片从纸张内点击进入尺寸属性；图片按受权内容哈希加载，核验字节和摘要，静态预览使用禁止脚本/外部资源的 iframe。当前只开放尺寸，换图继续等待上传预留、恢复与取消界面接通。

## 保存、连接与本机恢复

`WordBrowserState` 把房间状态、不可变原生投影、文本摘要、图片剩余意图摘要、provider 同步和本机落盘状态分开核验。每个房间 owner 发布 `stateId` 和递增 `stateSequence`；同版本迟到状态不能覆盖较新回执。新版本必须先通过原生布局核验，才能继续修改/导出。自动保存的短暂核验后恢复原有编辑焦点。

图片保存会消费已提交意图，因此保存前后的意图摘要可以不同。请求仍携带提交前摘要，由服务端核验；返回时核对服务端确认后的剩余摘要。新输入、新图片意图、未同步 provider、权限失效或冲突均不能据此关闭/导出。

建立过同步的连接一旦断开、收到文档级 CLOSE 或失去权限，旧实例被冻结；显式重试建立全新 Y.Doc，不能拿包含他人内容的旧完整状态自动重连提交。独立 `WordDeviceDraft` 按端点、账户、文档、epoch 和协议隔离，保留完整比较副本，但恢复只重放本机产生的更新。依赖缺失或不合法来源时保留下载，不借用当前人的身份重放同伴内容。

恢复选择先把自己的恢复更新持久化，再提交到新房间，最后推进已审阅水位。水位不会隐藏另一个窗口追加的更新，旧记录不删除。服务端签名恢复审阅 `WordRecoveryGate` 位于连接创建之前，本机副本审阅在新房间完成核验之后。设备下载副本不是完整 HCDZ。
