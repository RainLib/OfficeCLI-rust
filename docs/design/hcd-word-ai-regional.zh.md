# Word 区域 AI：私有建议、灰字补全与协同保存

2026-10-27。正文、页眉、页脚的区域编辑器现在复用已有 AI Provider、流式建议控制器、Notion 风格弹窗和自动补全组件。管理平台和实际提醒仍暂缓。此入口仍要求显式初始化的 `hcd-word-regions/1` 房间，不自动迁移旧文档。

## 接入方式

嵌入参数沿用 `aiExtensions`，不新增区域专用模型接口：

```tsx
import {EmbeddedHcdEditor, createHttpAiProvider} from '@officecli/hcd-reference-editor/react'

<EmbeddedHcdEditor
  documentId={documentId}
  token={documentToken}
  apiUrl="/v1/documents"
  collabUrl={collaborationUrl}
  locale="zh-CN"
  aiExtensions={{
    provider: createHttpAiProvider({url: '/api/document-ai'}),
    autocomplete: {enabled: false},
  }}
/>
```

宿主实现经过身份验证的同源 NDJSON 服务，遵循现有 `hcd-ai/1` 请求/事件协议。上面的 `/api/document-ai` 是宿主需要提供的接口，不是此仓库新增的模型网关。没有配置 Provider 时不调用模型；自动补全需要宿主显式配置，并可从“视图”功能区切换。

可通过 `aiExtensions.actions` 注册自定义操作、名称翻译、别名和指令，继续复用工具栏、右键、选区浮层和命令面板。区域不透明节点、人员提及和代码/链接等保护范围不作为普通文字交给改写。

## 操作和状态

- 选中文字后，可从选区浮层或功能区改写；光标处可续写。当前支持单个段落或标题中的纯文字范围。
- 空行按普通空格，或从 `/` 菜单选择 AI 助手，打开光标附近的提示词弹窗。中文组合输入、修饰键和普通正文空格保留原输入行为。
- 弹窗提供补充要求、流式建议、停止、重试、丢弃和明确接受。尚未接受的输出保留在当前窗口内存中。
- 可选自动补全显示灰字，完成且仍可见、聚焦、目标有效时才允许 Tab 或按钮接受。Esc 关闭；列表缩进、菜单和输入法优先处理按键。
- 块菜单、`/`、`@`、链接弹窗和 AI 弹窗会阻止补全。菜单状态按所属编辑器记录，其他页眉/页脚菜单关闭不会解除当前区域的阻止状态。

## 区域、权限和个人历史

`useSemanticAi` 提取控制器和弹窗生命周期，`createSemanticAiAdapter` 现在只要求结构选区接口及初始化状态，因此普通正文 store 与区域 view 可以共用。区域协作插件向所属编辑器暴露准确的 view；不会把整个文档当作单个区域。

每个控制器绑定具体编辑器和当前节/页眉页脚类型。切换区域、视图类型、Provider 或关闭编辑器，会取消旧任务；提交前也比较当前作用域。异步回执不会沿一个变化的 active-editor 引用写进另一个页眉或正文。

请求前、接受前均调用原生鉴权，核对身份、写权限、epoch 和协议。只读、断线、初始化未完成或个人历史执行中不能写入。CRDT 相对位置保持原选区身份：另一段或另一区域的输入可以保留；原选区文字、格式或结构改变会使建议失效。

接受只产生一笔普通文字事务，沿已有区域绑定、成员包守卫、个人历史和联合 checkpoint 保存。模型输出按文字插入，不执行 HTML。未接受建议和灰字装饰不进入共享正文、设备内容或文档导出。`onAccepted` 仍是宿主回调，不是原生持久化 AI 来源证明。

## 实际验证

隔离合成 fixture：`target/hcd-preview-runtime/word-room-tduug812`。使用真实嵌入入口、两名写成员、一名只读成员、生产 sidecar、原生服务和实际文件。模型部分为本机确定性 NDJSON 测试服务，**没有调用外部模型**。

| 行为 | 观察和文件证据 |
|---|---|
| 正文改写 | 接受前同伴看不到建议；接受后两端一致，r2 保存 |
| 个人撤销/重做 | 只反转本人的改写，保留另一成员的“同伴保留”输入 |
| 默认页眉改写 | r3 保存到独立页眉，首页页眉及原图片字节保留 |
| 页脚续写 | r4 保存到独立页脚，正文及页眉不被改写 |
| 未接受灰字 | r5 只保存实际输入的前缀，DOCX 中没有补全结果 |
| Tab 接受灰字 | r6 才出现补全结果，DOCX 中仅一处 |
| 目标被同伴修改 | 旧建议显示失效，接受按钮禁用，同伴文字继续保存 |
| 区域切换 | 切换首页/默认页眉后旧弹窗关闭，没有写入另一页眉 |
| `/` 与空行空格 | 均进入同一 AI 弹窗，保留截图 |
| 只读 | AI 生成、接受入口禁用 |
| 重开 | 前端完整重载后读取 r9，正文/页眉/页脚仍来自已确认版本 |

900 项前端测试、TypeScript 和生产/嵌入构建通过。新增区域测试使用真实 PM 绑定、Yjs 与房间守卫，检查跨区域目标拒绝、同伴正文保留及个人撤销重做；现有 AI 专项继续覆盖取消、授权等待、超时、迟到事件、目标失效和私有灰字。

实际浏览器下载的 r9 DOCX 与原生生成文件逐部件比较一致，仅排除导出时重新生成的 `w:paraId`。浏览器 HCDZ 解包后 r0–r9 编辑状态逐版一致，原生和离线包校验通过。测试请求不含 token、CRDT bookmark 或目标对象。

区域导出仍只开放 DOCX 和 HCDZ。实际请求 PDF、Markdown、HTML 时均得到明确 422“不支持区域格式”说明；本轮没有将其计为成功导出，也没有开放会丢失页眉页脚的部分导出。
