# 文档异常页与错误码

日期：2026-10-26。管理平台不在本次范围。

## 页面设计

打开失败使用统一的全页异常视图：保留文档标识和语言选择，中间显示文档图标、稳定错误码、原因和恢复操作。问题详情默认折叠，展开后显示发生阶段、可用的 HTTP 状态以及“复制错误信息”。主按钮为主动重试；宿主提供真实 `onClose` 回调时才提供“返回原应用”。不会自动循环重试或自动刷新页面。

正在检查权限、读取内容和检查草稿时使用一致的加载视图。已有草稿比较界面仍保留本机/服务器内容、选择、下载和恢复操作，错误显示为页内卡片。已打开的固定布局画布在刷新索引失败或切换完整编辑器失败时保留；保存与输入过程中的原有状态提示继续工作。本次没有将所有操作错误都改成整页异常。

正文显示异常由 React 错误边界处理；重试会重新挂载内容并经过普通恢复入口。它不会清空 IndexedDB，也不保证异常发生前尚未持久化的内存内容一定可恢复。

支持简体中文、繁体中文、英文；香港繁体和英国英文复用相应文案。窄屏布局、可折叠详情、语义化标题、按钮禁用状态和减少动画偏好均有样式/组件支持。

## 错误码

以下为编辑器的稳定展示错误码，HTTP 只是可选补充。不是 Rust API 的响应结构迁移。

| 错误码 | 含义和展示原因 | 典型触发 | 操作建议 |
| --- | --- | --- | --- |
| HCD-DOC-1000 | 打开文档的信息不完整 | 无效文档 ID、空凭证、HTTP 400 | 从原应用重新进入并检查参数 |
| HCD-DOC-1001 | 需要重新验证访问身份 | HTTP 401 | 从原应用取得有效凭证；不直接断言凭证过期 |
| HCD-DOC-1003 | 暂时无法访问此文档 | HTTP 403 | 由文档所有者确认权限 |
| HCD-DOC-1004 | 未找到可访问的文档或内容 | HTTP 404、410 | 检查链接和原始入口 |
| HCD-DOC-1009 | 文档版本或协作状态已变化 | HTTP 409、恢复时身份代次变化 | 重新检查最新状态，仍经过草稿恢复流程 |
| HCD-DOC-1026 | 需要兼容的编辑器版本 | HTTP 426、已知不支持的协作/内容模型 | 更新编辑器或联系应用管理员 |
| HCD-DOC-2001 | 暂时无法连接文档服务 | 请求层 TypeError，如离线/CORS/连接失败 | 检查连接后重试；不推断具体网络故障 |
| HCD-DOC-2002 | 文档服务暂时不可用 | 5xx（504 除外）、未能完成协作准备 | 稍后重试或提供错误信息 |
| HCD-DOC-2003 | 请求超时 | TimeoutError、HTTP 408、504 | 检查连接后重试 |
| HCD-DOC-2004 | 请求过于频繁 | HTTP 429 | 稍等后再试 |
| HCD-DOC-3001 | 无法解析文档内容 | 无效 JSON/响应字段、HTTP 422 | 重试；持续出现时由文档所有者或管理员排查 |
| HCD-DOC-3002 | 不支持此文档格式 | 未支持格式、HTTP 415 | 使用兼容应用或转换格式 |
| HCD-DOC-4001 | 本机草稿存储不可用 | 已明确包裹的浏览器草稿存储操作失败 | 检查存储；可用时显式选择不使用本机备份继续 |
| HCD-DOC-4002 | 本机草稿需要兼容版本 | 草稿与当前协作/内容模型不匹配 | 使用兼容版本恢复，不清除浏览器数据 |
| HCD-DOC-4003 | 无法确认本机草稿归属 | 固定布局恢复缺少稳定人员标识 | 从原应用重新进入；继续会禁用本机自动备份 |
| HCD-DOC-9000 | 文档暂时无法显示 | React 内容渲染异常 | 主动重试，检查可用草稿 |
| HCD-DOC-9999 | 未归类的打开异常 | 其他未识别失败 | 重试或提供错误信息 |

阶段为打开、读取内容、协作连接、本机恢复、显示文档。只使用受控文案；页面和复制诊断不包含原始响应、调用栈、URL、凭证、文档正文。诊断包含错误码、受控标题、阶段和可选 HTTP 状态，不发送遥测、不联系其他人。

## 实现与恢复约束

- `documentProblems.ts` 负责分类与三种语言文案；`DocumentProblem.tsx` 提供完整/页内异常、加载和错误边界。
- `documentSession.ts` 并行读取权限和文档元数据，检查格式/协作版本并支持取消、45 秒请求上限。替换参数和重试会取消旧请求，旧响应不能打开别的文档。
- 嵌入入口、独立登录入口、语义/分段入口、固定布局草稿恢复、固定布局内容请求、协作升级和表格启动失败接入共享视图。
- 固定布局只有实际磁盘操作才归类为本机存储失败。权限/服务错误不能通过“不使用本机备份”绕过。草稿下载与恢复保留原有流程；不自动清空草稿、不修改正文或导出协议。
- 表格启动异常以恢复层覆盖未完成启动的画布，保留宿主节点用于重试挂载；已有单元格保存错误保留原有拒绝补丁逻辑。
- 请求超时适用于网络请求；不声称浏览器 IndexedDB 操作本身已实现强制超时。

## 验证与边界

自动验证：696 项前端测试通过，其中新增 9 项覆盖 HTTP 映射、原始响应不进入诊断、多语言、原始网络错误在草稿包装中保留、标题结构、并行打开、非法参数/元数据/版本以及取消；连同已有草稿测试的定向回归共 14 项。TypeScript、独立及嵌入构建通过。

本机浏览器验证使用自有的故障代理：503、403、426 和损坏 JSON 是主动注入的测试响应。503 后点击重试，代理转发到真实本机 Rust API 和协作 sidecar，最终进入可编辑 DOCX，显示 r1 和“本机备份已记录”。另外验证了英文/繁体切换，以及 React 显示异常 HCD-DOC-9000 的捕获和重新挂载恢复。复制按钮显示成功，纯函数测试验证复制文本只含受控信息；本轮浏览器剪贴板读取工具返回空字符串，未独立证实系统剪贴板字节。

证据保存在 `docs/assets/hcd-document-problems-2026-10-26/`。没有把本机故障注入称为线上服务故障，也没有进行 Office 桌面软件验收、移动设备验收或新一轮文件导出验收。固定布局/表格专用启动错误已接入代码和构建，本轮未逐项执行这两种画布的故障注入。

设计预览：启动 Vite 后访问 `/document-problems.html`；可选择全部错误码、切换加载/页内状态、切换语言，并演练显示异常。该页面不包含凭证且不会修改文档，不属于生产入口。

故障流程复现（仅使用脚本创建的隔离文档）：

```bash
python3 scripts/hcd-mention-preview.py --runtime-dir target/hcd-preview-runtime --pages-prefix .hcd-document-errors
# 使用第一条命令打印的 root，保持其进程运行：
python3 scripts/hcd-document-problem-preview.py --root <隔离预览目录>
# 使用第二条命令打印的 retry/denied/invalid/upgrade 地址，在浏览器打开。
cd examples/hdoc/editor
npm test
npm run build
```

故障代理只绑定本机，凭证只写入临时且受限权限的测试页面，不写入报告；结束进程时移除自己创建的临时页面。测试账号凭证时效由预览脚本控制。设计页与报告可长期保留。
